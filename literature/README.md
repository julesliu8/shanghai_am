## 迁移后的共同结论

1. Selkirk & Shen 的低层实词边缘是候选倾向；其高层确定性MaP算法受到Roberts整句数据挑战。
2. Duanmu的重音、音步、长度和语速机制适合作为可检验机制，不是已证明的全句规则。
3. Roberts的AP、ip、IP和Sh_ToBI提供标注骨架；边界、音高事件、焦点、语境和句法必须分层。
4. 自然文本无法单独确定所有焦点和句调；受控问答与自然会话需并行。
5. 结构收益以特征增量和陌生句族迁移验证，不能以开发集命中或模型自己制造的标签证明。
