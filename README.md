# 上海话低资源变调界限预测

本项目当前只研究一个核心问题：给定一句上海话的文本、读音及合成前可知的结构信息，预测相邻音节之间是否存在低层变调域边界。标注单位是音节间隙，主要目标是预测口语中可观察的变调组或韵律词边界；为便于与现有文献和标注习惯衔接，文档中统一把这一层暂称为 `AP`（Accentual Phrase，重音短语）边界。

焦点、停顿、`ip`／`IP`、句末边界调和连续 `F0` 生成暂不作为研究问题、标签、模型输入或评价指标。它们只在解释排除标准、回顾历史方案或帮助人工判断边界时出现。Roberts的AM分析、Selkirk与Shen的低层边缘规则及Duanmu的非焦点音步机制均作为待验证的理论来源，不预设为正确答案。

## 文件位置约定

- `docs/00_原方案修订正文.md`、`04_近期任务清单.md`至`08_本科生视角文档评估.md`是当前现行文档。它们共同规定研究范围、标注口径、学习材料、理论验证和近期任务。
- `docs/01_实验方案.md`至`03_模型与数据划分.md`是前版工作记录。文件顶部已标明“不再执行”；其中关于焦点、停顿、高层韵律、句末事件和连续 `F0` 的设计不得混入当前实验。
- 两份现行Word分别位于 `docs/低资源条件下句法与构式知识辅助的上海话变调域预测研究.docx` 和 `docs/上海话变调界限预测学习与实验手册.docx`。它们由 `scripts/build_learning_documents.py` 从现行Markdown重建。
- `literature/`保存文献迁移说明和旧笔记线索；`literature/archive/`保存修订前快照。旧 `jieba` 笔记和前版Word只可用于追溯，不是当前标签规范。
- `stimuli/`：人工审阅的实验材料与问答语境，按句族编号。
- `data/raw/natural/`、`elicited/`、`blossoms/`：原始自然会话、人工设计后真人录音、电视剧素材，保留原文件。
- `data/metadata/`：录音来源、同意范围、说话人匿名编号和句族关系；身份对应表在受限位置独立保管，不放公开库。
- `data/annotations/draft/`、`adjudicated/`：预标注与裁决后TextGrid及结构JSON。
- `data/splits/`：冻结的训练、开发、最终测试清单；不按切片随机划分。
- `scripts/`：文档构建、文献提取、TextGrid初始化、边界检查和模型实验的可重跑脚本。
- `generated/`：文档渲染、原文提取、机器测量和检查报告；不得在此保存唯一人工修改，最终提交物仍放在 `docs/` 或 `deliverables/`。
- `models/`：配置与模型卡；`runs/`保存训练日志及预测。
- `deliverables/`：将来正式提交的冻结版本；当前两份Word均保存在 `docs/`，避免多个现行副本。

## 执行口径

- 第一批只做四类与低层分域直接相关的结构：`C01`实词与虚词附着、`C02`普通动宾与词汇化动宾、`C03`动补与潜能结构、`C05`复合词与长词。先完成96条中性语境小试，再依据自然度、招募和标注一致性决定是否扩样。
- 每个含 `n` 个音节的句子标出 `n−1` 个候选间隙；标签仅为 `0`（无AP边界）、`1`（有AP边界）和 `uncertain`（暂不能可靠裁决）。不把重音、停顿或标点直接等同于边界。
- 样本记录收敛为五类：音频元数据、音节及读音、词法结构、AP边界和质量控制。Praat核心轨道收敛为 `syllable`、`word`、`AP`、`misc` 四轨。
- 模型按 `L0–L4` 逐层增加文本、读音、词法、结构和可选计划语速信息。评价报告边界Precision、Recall、F1、整句边界序列完全匹配率和Top-k候选；所有划分先按说话人和句族隔离。
- `F0`曲线和听感只能帮助人工判断与质检，不能作为文本侧边界预测模型的输入。录音后的实测时长或停顿也不得泄漏给面向TTS前端的模型。
