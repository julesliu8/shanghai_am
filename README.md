# 上海话整句韵律与低资源变调域预测

本目录承接原课题方案，研究词法、句法、构式和语境怎样帮助预测上海话整句的变调域与较高层韵律。目标人群以中青年市区上海话使用者为主，年长者作对照。Roberts的AM分析作为可检验的理论与标注起点，不直接作为正确答案。

## 文件位置约定

- 原方案现位于 `docs/低资源条件下句法与构式知识辅助的上海话变调域预测研究.docx`，按用户要求直接修订；修改前备份位于 `literature/archive/原方案修改前_低资源条件下句法与构式知识辅助的上海话变调域预测研究.docx`。
- `docs/`：当前实验方案、术语与标注手册、神经网络及数据划分协议、任务清单。
- 本科生入门补充统一写入 `docs/07_本科生导读与术语例解.md`，阅读障碍审查记录写入 `docs/08_本科生视角文档评估.md`；07与05、06合编现行学生Word手册。构建脚本仍在 `scripts/`，本轮校验与页面图写入 `generated/student_guide_20260909/`，修订前手册快照写入 `literature/archive/`。
- `literature/`：文献证据表及旧笔记的总结；`literature/archive/`保存旧笔记快照，历史笔记不是新标注规范。
- `stimuli/`：人工审阅的实验材料与问答语境，按句族编号。
- `data/raw/natural/`、`elicited/`、`blossoms/`：原始自然会话、人工设计后真人录音、电视剧素材，保留原文件。
- `data/metadata/`：录音来源、同意范围、说话人匿名编号和句族关系；身份对应表在受限位置独立保管，不放公开库。
- `data/annotations/draft/`、`adjudicated/`：预标注与裁决后TextGrid及结构JSON。
- `data/splits/`：冻结的训练、开发、最终测试清单；不按切片随机划分。
- `scripts/`：提取文献、初始化TextGrid、导出声学测量和检查数据的可重跑脚本。
- `generated/`：原文提取、论文页面图、机器测量、检查报告；不得在此保存唯一人工修改。
- `models/`：配置与模型卡；`runs/`保存训练日志及预测。
- `deliverables/`：将来正式提交的冻结版本；当前两份Word均保存在 `docs/`，避免多个现行副本。

## 执行口径

- 第一批聚焦条件句、复杂宾语与句子焦点、词内对比、句末事件四项；其余构式作为扩展。先做96条小试，扩样取决于自然度、实际招募和标注成本。
- 自然口语60分钟是可用材料目标，训练／开发／测试目标为36／12／12分钟；先按说话人和会话关系隔离，再尽量接近比例。人工材料按句族隔离，同句各语境和重复不得跨集合。《繁花》先作为独立来源测试。
- 九层为本项目数据组织方案，不等于Roberts原有标注层数。示例的时间、调值与分域均明确标为教学假设，不能进入模型训练或测试。
