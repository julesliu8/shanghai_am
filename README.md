# 上海话低资源变调界限预测（AM project）

更新：2026-09-14

## 研究内容

本项目研究自然上海话中相邻音节之间的低层变调域（暂称 AP）边界。输入是文本、候选读音及合成前可知的结构信息；声学分析用于提出可审阅线索，不能替代人工裁决。

## 目标

建立可解释、可复算的机器预标注流程，比较文本/读音/结构基线与声学线索，并为后续双人标注、边界预测和 TTS 前端提供证据。

## 核心进度

- 已归档录音11及双轨句段；音轨1有593个索引句段、9362个汉字候选。
- 已完成候选字界、无调音素对齐、raw/filtered F0与H/L机器对照；当前候选仍未全部人工听校。
- 已完成0028感知特征对照，以及音轨1 /i/、送气声母起始F0全量筛查。
- 已建立文献总表（22号）和专题记录（24–31号）；跨语言声母—onset F0综述见31号。
- 当前模型与声学结果均是研究工具，不是正式 AP 金标准或人耳感知模型。

## 已回答的重要问题

- F0高度、F0运动、时长、发声态和语境必须分开分析；没有可直接移植到自然上海话的固定感知公式。
- 送气和清擦音后常见起始F0偏高/随后回落，但“翘头”不是跨语言必然规律；浊音常见相反的depressor效应。
- 音轨1的粗分组中送气后的下降较多；同部位、同韵母的配对未显示稳定的额外 /i/×送气效应。不能统一删掉高起点或减去固定半音。
- 0034“体”、0034“系”、0036“请”的有声主体下降有波形/逐周期支持，但边界、辅音和鼻尾仍需人工核验。

## 待回答的问题

- AP边界的人工金标准、双人一致性及听感阈值。
- 词调、变调域、焦点、语速、声母部位、VOT和发声态的可比控制。
- 音轨归属、候选读音和字界的逐步听校；短韵母和F0缺测的正式规则。
- 声学线索如何进入透明规则，并在独立听辨与TTS中验证。

## 下一步规划

1. 优先听校缺测、弱支撑、/i/×送气及同部位同韵母配对。
2. 冻结少量人工参考，校准D、时长、VOT和发声态的拒判条件。
3. 进行双人标注与分歧裁决，再运行AP基线和逐层模型。
4. 在独立语料验证规则和TTS边界效果；不把跨语言平均值当作上海话修正常数。
