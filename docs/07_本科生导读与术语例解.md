# 上海话整句韵律本科生导读与术语例解

这份导读写给这样的读者：学过一点语言学，知道句法、语义、语音大致研究什么；也接触过机器学习或大语言模型，但没有读过本项目的核心论文，对声调、连读变调和韵律层级还不熟。读完后，你不必立刻同意任何一套理论，但应该能看懂项目文件、论文图例、TextGrid标签和模型输入，并知道哪些内容是事实、哪些是分析、哪些只是待检验的预测。

本文不是新的标注标准。现行实验口径仍以00、05、06号文档为准；本文负责补足背景、缩写和例子。所有写着“教学假设”“可能”“候选”的分域、读音和音高数值都不能直接进入正式数据。

## 0 第一次进入项目应该先抓住什么

### 0.1 一句话版研究问题

本项目要回答的是：给定一串上海话文本及必要的读音、句法、语境和说话方式信息，能否预测说话人会把整句话分成哪些变调域和更高层韵律单位，并进一步帮助TTS读得自然。

这里有四个不能省掉的限定。

1. 研究对象是整句和自然话语，不只是孤立的二字词、三字词。
2. 输出不只有“哪里断开”，还包括边界有多强、有没有真实静音、有哪些音高事件以及句末语调。
3. 同一句文字可能有多个自然读法。没有语境时，模型不一定应该只输出一个答案。
4. 句法、构词、焦点和语速都是候选解释因素，不是预先规定的真理。

### 0.2 把任务想成从文本到声音之间的一座桥

可以先用一条流水线理解项目：

`文本与词典读音 → 词法和句法结构 → 语境与焦点 → AP ip IP等韵律结构 → 音高与时长实现 → TTS声音`

每个箭头都可能出错。例如，“阿爸勿欢喜姆妈个礼物”若分词错误，后面的句法跨度会错；句法即使正确，纠正语境和普通回答也可能产生不同的焦点后弱化；韵律边界即使预测正确，句末的H%或L%仍可能生成错误。因此项目把问题拆层，而不是让一个大模型直接从汉字跳到最终曲线后再猜它学到了什么。

### 0.3 项目名里的AM不是某个AI模型

AM是`Autosegmental-Metrical`的缩写，常译作“自主音段—节律”或“自主音段—格律”。在本项目里，它首先指Roberts采用的一类音系表示方法：把H、L等音高目标与音节、突出位置和短语边界分别表示，再说明它们怎样关联和在时间中实现。

“自主音段”可以先理解为：声调目标不是必须像贴纸一样逐字固定在某一个字符上，它可以单独表示，再与某个音节、短语首尾或突出位置建立关联。“节律”可以先理解为：句子内部有强弱和层级组织，不同位置的目标地位不同。AM不是LLM，不是神经网络架构，也不是“自动标注模型”。Roberts的AM分析是本项目要检验和借用的理论起点之一。

### 0.4 推荐阅读顺序

零基础读者不宜从模型参数表开始。建议按以下顺序：

1. 先读本文第1至4节，弄懂声调、变调域、AP、ip、IP、焦点和句法缩写。
2. 再读05号文档第1、2、6、7节，观察这些概念怎样落到同一句话的九层标注。
3. 接着读05号文档第3至5节，比较S&S、端木和Roberts。
4. 然后读06号验证卡，练习把理论命题写成可反驳的实验。
5. 最后再读00号总体方案和03号模型记录；这时L0至L4、T1至T3、F1等符号才不会混在一起。

如果只有三十分钟，先掌握三组区别：词界不等于AP界，AP界不等于停顿；音高重音不等于句子焦点；理论预测不等于录音标签。

## 1 音系学最小基础

### 1.1 音系学与语音学分别在问什么

语音学关心声音怎样发出、传递和测量，例如某段基频是多少Hz、某个音节持续多少毫秒、波形中有没有静音。音系学关心一种语言怎样用声音形成对立和组织，例如哪些调类能区别词义、哪些音节在连读时保留或改变声调、说话人把哪些音节看作一个韵律单位。

二者不能分家，但结论层级不同。录到一个120 Hz的点是语音测量；把它分析成L目标是音系解释。看到“来”后0毫秒静音是测量；把“来”后判断为ip边界则还需听感、延长和后续重置等证据。

### 1.2 音节 字 语素 词不是同一个单位

项目经常逐音节对齐，但一个汉字、一个语素、一个音节和一个词并不总是一一对应。

- 音节是语音节奏和切分单位，例如“小李”通常包含“小”“李”两个音节。
- 字是书写单位；同一个字可能有不同读音，同一个音节也可能对应不同字。
- 语素是最小的有意义单位。“礼拜三”中的“三”可以在纠正语境中单独形成对比。
- 词是词法单位。“小李”可作为一个专名词，但仍有两个音节。

因此C层可以把“小李”标成一个词区间，B层仍必须保留两个音节，F层的AP又可能与词层相同或不同。

### 1.3 调类 调值 音高和F0

“声调”至少要拆成四个概念。

1. 调类是词典或音系系统里的类别。本项目保留传统T1至T5，目的是记录一个词项来自哪一类对立。
2. 调值是对高低走势的概括，例如高、低、升、降或数字调值；它不是某一次录音的全部细节。
3. 音高是人的听觉感受，受到基频、响度、音质和上下文影响。
4. F0是`fundamental frequency`，即基频，是声带周期振动的物理测量，单位通常为Hz。

F0和音高密切相关，但不完全等同。气声、喉化、清辅音或跟踪算法错误可能让F0缺失或跳倍频。此时不能把“没有可靠F0点”解释成“说话人发了最低调”。数据中应写NA或`tracking_missing`，而不是0 Hz。

### 1.4 为什么比较音高常用半音而不是直接减Hz

人的音高感知更接近比例变化。110 Hz到125 Hz相差15 Hz；220 Hz到235 Hz也相差15 Hz，但听起来不是同样大的相对变化。半音换算常写作：

`半音差 = 12 × log2(后一个F0 ÷ 前一个F0)`

例如125相对110约高2.2个半音。这个数仍不能单独证明“音高重置”：两个音节的词汇调类若不同，本来就可能有不同起点；还要与同一个人的匹配对照比较。

### 1.5 单字调与连读变调

单独念一个字时记录的声调可称单字调或citation tone。字放进词和句子后，调形可能按一定模式改变，这就是tone sandhi，中文通常说连读变调。

上海话的重要特点之一，是若干音节可以组成一个低层变调域，域首的词汇调信息对整个域的曲线组织有重要作用，域内后续音节不一定各自完整保持单字调。初学者容易把它误解成“第一个字把后面所有字都改成固定调值”。更谨慎的说法是：域首调类、域长、发声态、焦点、相邻目标和句末语调共同决定实际实现，且不同说话人或语境可能分域不同。

### 1.6 什么是变调域

变调域是若干音节共同参加某套变调组织的范围。教学时用圆括号表示候选域，例如：

`(礼拜三)`

表示三个音节暂分析为一个低层域；

`(礼拜)(三)`

表示“三”另起一个域。圆括号不是停顿符，也不是词界。说话人完全可能在两个相邻域之间不停顿。

“域”本身是分析概念，不能只靠一条证据决定。至少要结合域首词汇目标是否出现、域内目标怎样展开、边界听感、时长和相邻调目标等信息。

### 1.7 韵律是什么

韵律是超出单个辅音和元音的组织，包括音高、时长、强度、节奏、停顿、突出和层级分组。它不是“语调”的同义词，也不是只研究好不好听。

可以把“假使伊来，小李就要走”想成乐句。词汇声调像每个局部动机的材料；AP决定若干音节怎样组成小单元；ip把小单元组成较大的段落；IP组织完整语调轮廓。焦点和语速会改变演奏方式，但不会自动改写句法树。

### 1.8 边界 停顿和书写标点

边界是说话人在韵律上把两侧组织为不同单位；停顿是可测的静音；标点是书写约定。三者相关但不等同。

- 有逗号，不保证说话时一定停顿。
- 没有静音，也可能有末音节延长、后续音高重置和较强听感，从而支持ip边界。
- 有静音，也可能只是犹豫、口误、换气或录音中断，不能直接当成语法边界。

因此项目分别保存`clause_edge`、Break等级和`pause_ms`。一个字段不能代替另外两个。

### 1.9 突出 重音和焦点

这三个词最容易混用。

- 突出prominence是听觉或声学上某部分更显眼，可能表现为音高、时长、强度或音质差别。
- 重音stress在不同理论中含义不同。端木的重音分析涉及音步强弱和默认突出，并不都等于语义焦点。
- 焦点focus是信息结构概念，指当前回答、纠正或对比的内容范围。

例如问“啥人要走”，回答中的“小李”是窄焦点；纠正“是老王要走”时，“小李”是纠正焦点。两种情况下“小李”都可能突出，但后续音高变化未必相同。反过来，一个AP域首可以带H*或L*，并不表示说话人语义上专门强调它。

## 2 AM表示法和符号怎样读

### 2.1 先只记住H和L

AM表示中的`H`来自high，表示高音高目标；`L`来自low，表示低音高目标。它们是相对目标，不是全体说话人共用的固定Hz值。某位说话人的H可能低于另一位说话人的L，所以实验通常做说话人内比较或归一化。

一个目标写成H还是L，是音系分析；曲线在某一时刻测得多少Hz，是语音实现。实际曲线会受到调类、音段、语速、句子位置和相邻目标影响，不一定画成完美直线或尖角。

### 2.2 星号 加号 字母a和百分号分别做什么

把常见符号逐个拆开：

- `H*`：一个高目标与突出音节关联。星号`*`表示关联位置，不表示“非常高”或“重点提醒”。
- `L*`：一个低目标与突出音节关联。
- `L*+H`：突出音节上先有L*，随后还有H目标。加号表示两个目标属于一个组合事件，不是数学加法。
- `La`：AP末端的低目标。这里的小写`a`提示它与accentual phrase层级相关；它不是句子焦点标签。
- `L:a`：AP末低目标的一种低平台实现。冒号是该分析中的形式记号，不是时长测量值。
- `LHa`：AP末端由低向高的复合边界事件。
- `H%`：IP末端的额外高边界目标。百分号`%`表示语调短语边界层级。
- `L%`：IP末端的额外低边界目标。
- `%`：IP边界存在，但没有额外指定H或L目标。它不等于“没有语调”。

最重要的阅读技巧是看后缀。`H*`和`H%`虽然都有H，但前者与突出音节关联，后者与IP末端关联；不能把两者当成“都是升调”。同理，`La`属于AP末端，`L%`属于IP末端，二者可以在同一句末附近互动。

### 2.3 括号 尖括号和焦点记号

Roberts式标注中还会遇到以下记号：

- 圆括号包住音高事件，表示该事件在弱化环境中受到抑制或不明显，但分析上保留其来源。不能未经检验就把它从词汇表示中删除。
- `<`和`>`记录目标相对其正常关联位置的延后或提前。它们表示时间对齐变化，不是“大于”“小于”的数值比较。
- `aF`表示普通窄焦点，F来自focus。
- `aC`表示纠正焦点，C来自corrective。
- `i`在Roberts的Tones层中用作中间短语边界的标记。它提示ip层级，不是又一种词汇声调。

项目把“提示想诱导的焦点”和“录音中实际观察到的突出”分开存储。即使提示是aC，受试者没有成功表达纠正，也不能把全部声学现象强行解释成纠正焦点。

### 2.4 AP ip IP是三级不同单位

`AP`是`Accentual Phrase`，本文译作音高重音短语。它是主要承载低层变调组织的韵律单位，大致对应本项目首先要预测的变调域。大致对应不等于永远完全相同。

`ip`是`intermediate phrase`，即中间短语。它比AP高一层，可以包含一个或多个AP。典型诊断包括较强的边界听感、边界前延长和边界后音高重置；Roberts讨论的典型ip边界后没有真实静音，所以“无静音”不能用来排除ip。

`IP`是`Intonational Phrase`，即语调短语。它比ip更高，组织较完整的语调轮廓，末端可有H%、L%或%，常伴末端延长和随后静音，但不等于书面句号。

可以画成层级：

`音节 < AP < ip < IP`

例如教学假设：

`[[ (假使)(伊)(来) ]ip [ (小李)(就要)(走) ]ip ]IP`

圆括号是AP，方括号是ip，最外层是IP。该式只演示嵌套关系，不宣称这是目标句的唯一正确读法。

### 2.5 为什么ip小写而IP大写

大小写是术语的一部分，不是排版随意。`ip`指中间短语，`IP`指语调短语。若数据库统一转成大写，两层会合并，模型就无法学习边界强度。文件名、JSON枚举、标签表和论文摘录都必须保留大小写。

可以用“中间层小写，最高层大写”帮助记忆，但写代码时不要靠记忆猜，应使用固定枚举和校验器。

### 2.6 AP为什么还可能表示形容词短语

在句法学教材里，AP常被用作`Adjective Phrase`，即形容词短语。为避免冲突，本项目规定：

- 韵律层的`AP`只表示Accentual Phrase。
- 句法层的形容词短语写`AdjP`。

看到AP时先问它属于哪一层。若它与H*、Break、变调域一起出现，通常是音高重音短语；若它与NP、VP、中心语一起出现在句法树中，则原文可能是形容词短语，项目录入时应改写为AdjP。

### 2.7 Break 0到4记录的是连接强度

Break index可译作边界指数或连接强度等级。数字写在相邻音节之间：

| Break | 初学者版解释 | 不应误解为 |
|---|---|---|
| 0 | 比普通AP内部还紧，可能有音段缩短或丢失 | 两个字一定成为一个词 |
| 1 | 普通AP内部连接 | 没有任何音系组织 |
| 2 | 两个AP之间 | 必有静音或逗号 |
| 3 | 两个ip之间，即较强边界 | 必定是两个句法小句 |
| 4 | 一个IP结束后 | 只要看到句号就填4 |

层级一致性要求：若某位置是3或4，它至少也应是AP边界。反过来，一个AP边界通常是2，不必升级成3。项目不把数字当连续物理量；3不是“比2多停一半时间”。

### 2.8 Break后的m p和减号

附加记号保留困难实例：

- `m`来自mismatch，表示数字等级与部分线索或听感不完全匹配，例如`2m`。
- `p`表示口误、不流利等特殊实现，例如`1p`。
- `-`表示不确定或介于相邻等级，例如`2-`。

不能为了方便训练把`2m`全改成2，也不能自行创造2.5假装精确。可以在主任务中屏蔽不确定项，同时把它们保存在专门的误差分析集合。

### 2.9 一个完整符号串怎样逐步读

假设某个教学AP被标成`L*+H ... La`，IP末又有`H%`。正确阅读顺序是：

1. 找星号：L*与突出音节关联。
2. 看组合：随后还有同一音高重音事件中的H。
3. 找小写a：AP末端有低目标La。
4. 找百分号：更高层IP末端还有H%。
5. 再看时长：若末AP很短，La和H%可能拥挤，La可能提前、与其他目标结合或不显现。
6. 最后看实际F0和音质，判断理论目标是否有可靠语音证据。

不能从曲线上“只看到一个上升”就跳到“这里只有H%”。上升可能同时包含词汇事件、AP尾事件和IP尾事件的互动。

### 2.10 AM表示与传统T1至T5是什么关系

传统T1至T5记录词典调类；Roberts为其研究人群提出H*、L*+H、L*三类较抽象的词汇音高重音表示。两套标签回答的问题不同。

例如多个传统调类可能都映射到L*+H，但仍因清浊、气声、喉塞韵尾和时长而有不同实现。项目因此同时保存`citation_tone=T1...T5`、音段属性和实际AM事件。模型实验可以比较哪套表示对未见词项更有效，却不能因为三类模型误差较小就宣布语言只有三个音位调。

还要注意：03号文档中的任务T1、T2、T3不是调类。建议代码和表格使用`tone_class_T1`与`task_T1`这类显式名字，避免同一个“T2”一会儿指调类、一会儿指结构到韵律任务。

## 3 读懂项目所需的词法和句法

### 3.1 词性缩写

项目中的词性标签可能来自不同标注体系，大小写也可能不同。现行教学例常用以下英文缩写：

| 缩写 | 英文 | 中文 | 例子中的作用 |
|---|---|---|---|
| N | noun | 名词 | “书”“礼物” |
| V | verb | 动词 | “来”“走”“欢喜” |
| A | adjective | 形容词 | S&S原文所说实词类别之一 |
| ADV | adverb | 副词 | “就”在示例中的候选词性 |
| PRON | pronoun | 代词 | “伊” |
| PROPN | proper noun | 专名 | “小李” |
| CONJ | conjunction | 连词 | “假使” |
| MODAL | modal | 情态成分 | “要” |
| P | preposition | 介词或介引成分 | 嵌入和处所结构中需具体裁决 |

`仔`、`勿`、`个`等方言成分不能只凭字形套普通话词性。旧`jieba/legacy/backups/claude.md`还记录了`va`补语形容词、`vn`词汇化动宾词等工程标签，这些是旧分词项目的局部约定，不自动等于AM项目的句法真值。迁移时必须同时保存原标签、释义和当前裁决。

### 3.2 短语缩写

| 缩写 | 英文 | 中文 | 初学者抓手 |
|---|---|---|---|
| NP | noun phrase | 名词短语 | 以名词性成分为中心，如“姆妈个礼物” |
| VP | verb phrase | 动词短语 | 以谓词为中心，如“勿欢喜姆妈个礼物” |
| AdjP | adjective phrase | 形容词短语 | 项目特意用AdjP避开韵律AP冲突 |
| DP | determiner phrase | 限定词短语 | S&S数量表达分析中的理论候选 |
| S | sentence或clause | 句子或小句 | 示例树的总节点 |

短语不是“字数大于一的词”。单个代词“伊”也可构成NP；一个多字固定词又不一定在句法上包含多个短语。

### 3.3 中心语 修饰语 补足语和非中心语

中心语head决定短语的核心类别。例如“姆妈个礼物”整体是名词短语，中心语通常分析为“礼物”；“姆妈个”提供领属或修饰信息。补足语complement与中心语关系紧密，例如宾语与动词的关系；修饰语modifier提供额外描述。

非中心语nonhead只是“不是中心语的部分”，不等于不重要。端木的`Nonhead Stress`主张某些结构中默认突出落在非中心语。例如复合词“纸箱”中“纸”修饰“箱”，与动宾“买书”中宾语“书”的默认突出位置可能不同。这里的突出候选仍不能直接当作最终AP边界。

### 3.4 语素 词汇化和能产性

词汇化lexicalization指一个组合经过长期使用后更像固定词，整体意义或读法不完全等于临时组合。能产productive表示说话人能用规则自由创造新组合。

“礼拜三”中的“三”有清楚的可替换系列，纠正“三／四”时可能独立突出；某些高度词汇化的三音节词则可能只允许整体扩展。若实验发现两类表现不同，不能总结成“焦点有时拆、有时不拆”就结束，而应检验词汇化程度、内部结构和调类是否提供条件。

### 3.5 Lex零 Lex最大和XP

S&S规则里的`Lex⁰`读作“词汇零阶投射”或“词汇中心语层”。上标零不是第零号词，而是句法层级记号。其经验范围主要涉及N、V、A等词汇性或实词中心语。

`Lex^max`表示词汇中心语的最大投射，即该中心语连同相关补足语和修饰语构成的完整短语。文献中也会写`LexXP`来泛指词汇性最大投射。`XP`是句法理论中“某一类X短语”的通式；X可替换成N、V、A等。

初学者最容易犯的错是把“最大”理解成整句最长字串。最大投射是结构关系，不按字符数定义。`[姆妈个礼物]NP`可以是名词“礼物”的最大投射，即使整句更长。

### 3.6 PW和MaP

`PW`是`Prosodic Word`，即韵律词，是S&S低层规则使用的名称。它是韵律单位，不必与词典中的正字法词一一对应。

`MaP`是`Major Phrase`，即主要短语，是S&S讨论焦点后范围和高层组织的单位。按其分析，MaP左边缘与某些`Lex^max`左边缘对应。MaP不是Roberts的`ip`换一个名字；两套理论的定义和识别方法不同，实验需要比较它们对同一位置的预测。

### 3.7 局部句法与全句句法

局部句法关注相邻成分关系，如动宾、动补、数量、体貌、词内构词。全句句法关注主句与从句、话题、嵌入、关系小句、长距离依赖和省略。

项目把它们拆成D层和E层，是为了测量标注成本与预测收益。若完整树只在关系小句中明显提高边界预测，就可以只对相关构式精标，而不要求每条自然会话都先完成昂贵的深层树。

### 3.8 构式和句族

构式construction是形式与功能的常规组合，如条件句、关系小句、正反问、动补结构。项目编号C01至C08表示八类构式族，不是八个声调类别。

句族sentence family指围绕同一词项、结构和目标对比建立的一组材料。同一句的不同语境、重复读法和近似改写通常属于同一句族。模型划分时整个句族必须放在同一侧，否则模型可能记住字串，造成测试泄漏。

### 3.9 广焦点 窄焦点 纠正焦点和话题

广焦点broad focus表示整句话或较大成分都是当前新信息。例如问“发生啥事体了”，回答整个事件。

窄焦点narrow focus只更新较小成分。例如问“啥人要走”，回答“小李”。普通窄焦点不一定带反驳。

纠正焦点corrective focus明确否定先前假设。例如对方说“老王要走”，回答“是小李要走”。它往往更强，但“纠正”是话语功能，不等于情绪激动。

话题topic是句子正在谈论的对象，常是已知或先提出的信息。“搿本书，我看过”把“搿本书”放在话题位置，但它也可能同时带对比。话题、焦点、已知信息、新信息不是互相排斥的单标签列表，需要结合具体问答记录。

### 3.10 句法结构不能从目标录音反推

若标注者先看到某处变调域断开，再把该处结构标成NP边缘，随后声称“NP边缘准确预测了断开”，就形成循环论证。正确顺序是：结构标注者依据文本、释义和独立语法诊断给出树；语音标注者独立听录音；最后才比较二者。

这也是项目强调“冻结结构”和“盲标”的原因。冻结不是说结构永远正确，而是说主要分析开始后不能为了迎合每条声调结果随意改树。

## 4 三套理论各自在解释什么

### 4.1 不要把三套理论想成同一道选择题的三个答案

S&S、端木和Roberts的出发点不同。

- S&S重点说明句法中的词汇成分边缘怎样映射为低层和较高层韵律域。
- 端木重点追问重音、音步、长度和语速是否能比固定词界更统一地解释低层分域。
- Roberts重点为整句建立AP、ip、IP和音高事件的表示，并讨论焦点、边界和目标互动。

它们有重叠，却不是三套接口完全相同的端到端算法。一次实验可能支持S&S的低层实词边缘，同时挑战其高层MaP强规则；也可能支持Roberts区分AP与ip，却无法判断其三类词汇音高重音是否适合年轻人。

### 4.2 S&S指谁

`S&S`指Elisabeth Selkirk与Tong Shen合著的1990年章节`Prosodic domains in Shanghai Chinese`。项目关注两条映射：

1. `Left Lex⁰`：词汇性中心语的左边缘与低层韵律单位左边缘相关。
2. `Left Lex^max`：词汇最大投射的左边缘与较高层MaP左边缘相关。

“老师买仔书”的教学推导如下。先独立标词性：老师=N，买=V，仔=体貌功能成分，书=N。再在实词左边缘建立低层候选，功能成分可能附着，于是得到教学预测`(老师)(买仔)(书)`。如果实际词法身份不同，理论输入也会不同。

S&S的价值在于提供可递归应用的结构规则，而不只是列出每个词的读法。其风险是确定性过强：长度、词汇化、语速、焦点和说话人变异可能使同一结构出现不同分域；`Lex^max`本身也必须有独立句法依据。

### 4.3 Top Down Effect是什么意思

`Top-Down Effect`是“高层对低层的制约”。若低层附着会跨越一个较高层MaP边界，层级结构就发生交叉；S&S因此让高层边界迫使低层单位在该处断开。

可以把它想成文件夹：音节先装进PW，PW再装进MaP。一个PW不能同时跨在两个MaP里。但这个比喻只解释形式要求，不证明某位置实际就是MaP；高层边界的来源仍需独立检验。

### 4.4 端木分析中的D是什么

`D`是本项目对Duanmu，即端木三的简称，不是一个通行理论缩写。05和06号文档中的D1、D2、D3只是教学小节或验证卡编号。

端木把低层变调域与重音和音步联系起来。`foot`译作音步，是若干音节构成的节律单位；`left-headed foot`或左头音步表示左端位置较强。希腊字母`σ`表示音节，所以`(σ1 σ2)(σ3 σ4)`只是四音节串分成两个二音节音步，数字不是声调值。

“老虎头”的例子展示焦点可能重组域：普通语境可候选为`(老虎头)`；纠正“不是老虎尾，是老虎头”时，“头”获得额外突出，候选变成`(老虎)(头)`。推导链应写成“语境要求对比→独立确认突出→音步或域重组→域首调实现”，不能倒过来用新调形定义突出。

### 4.5 端木理论为什么要检验语速和词汇化

若较长单位慢读时拆成两个域、快读时合成一个域，严格的一词一域映射就不充分。但“快读曲线更平”也可能只是音段缩短和一般弱化。只有当域首目标、边界听感等也系统变化，才支持音系重组。

词汇化也可能保护整体读法。实验需比较多个相同长度、不同内部结构的词项，并在同一说话人内操纵速度。否则“上海语言学校”一个候选的两种读法无法区分长度、熟悉度、结构和个人习惯。

### 4.6 R和Roberts的核心贡献

`R`是本项目对Brice David Roberts及其2020年UCLA博士论文的简称。论文题为`An Autosegmental-Metrical Model of Shanghainese Tone and Intonation`。

Roberts的主要贡献不是从任意文本自动预测唯一分域，而是为整句语音提出一套分层分析：

1. 用H*、L*+H、L*等词汇音高重音组织AP。
2. 在AP之上区分ip和IP。
3. 区分AP尾事件与IP尾H%、L%、%。
4. 记录焦点后的弱化、目标提前或延后和Break等级。
5. 指出同一字串和句法可出现说话人间或说话人内变体。

该论文主要分析出生于1937至1975年的中部市区上海话说话人，不能未经实验直接当成年轻上海话标准。它的分层标注思想可借用，具体类别仍需在本项目人群中双人试标和验证。

### 4.7 Sh ToBI是什么

`ToBI`是`Tones and Break Indices`，可译作“声调与边界指数”标注框架。`Sh_ToBI`是Roberts面向上海话建立的版本；`Sh`表示Shanghainese。它包含Tones、IPA、Hanzi、English、Breaks、Translation和Miscellaneous等层。

本项目的九层A至I不是Roberts原有七层换名。我们把音频元数据、词法、句法、语境和机器学习需要的字段扩展进去，并把Praat中真正需要打开的轨道控制为六条左右。引用时应写“以Sh_ToBI为起点扩展的项目九层方案”，不能写成“Roberts提出九层”。

### 4.8 三套理论在同一句上怎样提出不同问题

看“阿爸勿欢喜姆妈个礼物”。假定“姆妈个礼物”是一个NP，焦点落在“勿欢喜”。

- S&S问题：宾语NP的`Lex^max`左边缘是否建立MaP，从而限制焦点后删调越过“姆妈”？
- 端木问题：默认重音、音步、词长和语速能否解释实际低层分域，而不只靠NP左边缘？
- Roberts问题：普通窄焦点和纠正焦点是否造成不同的后焦点弱化；这些变化发生在几个AP和哪个IP内？

同一录音可以同时用于多个比较，但标签必须先独立建立。若后续F0整体下降而词汇目标仍可辨，只能说register lowering或调域降低，不能直接说音系删调；若目标因喉化无法跟踪，则证据不足。

### 4.9 后来的Match Theory放在哪里

`Match Theory`通常指Selkirk后来提出的句法—韵律对应约束，如`Match Clause`、`Match Phrase`和`Match Word`。它允许句法成分倾向对应韵律成分，同时承认节律、焦点、已知信息和语言特定约束可以造成重组。

它提供一个有用的中间立场：句法不是无关，也不是机械一一映射。但本项目尚未取得一套已经为当代上海话确定好约束排序的完整Match算法，因此它适合作为扩展理论，不应在标注前直接生成gold。

### 4.10 理论被支持或挑战应该怎样写

好的结论有对象、条件、现象和范围。例如：“在本研究中青年市区说话人、纠正语境和所测复杂宾语中，NP左边缘没有稳定阻断后焦点弱化。”

不好的结论是“S&S错了”“端木是对的”“AM得到证明”。一条局部规则失败不等于整套理论无价值；一个模型准确率更高也不等于其内部表示就是人的心理机制。

## 5 五个从问题到标注的例子

### 5.1 例一 条件句中的AP界和ip界

目标句候选：“假使伊来，小李就要走。”释义：“如果他来，小李就要走。”

第一步看句法。前四个音节“假使伊来”构成条件部分，后五个音节“小李就要走”构成主句。句法上“来｜小”之间有小句交界。

第二步看低层韵律。教学假设可把句子分成`(假使)(伊)(来)(小李)(就要)(走)`六个AP。这里“来”后已经是AP边界，所以Break至少可候选为2。

第三步看高层韵律。一种读法可能只有普通AP连接，“来”后为2；另一种读法可能让条件部分形成独立ip，“来”后为3。两种读法可以使用同一棵句法树。

第四步看声学证据。若“来”延长、听者感到较强分组、后面同类目标出现重置，而中间没有静音，这组证据与ip相容。若只有逗号或只有曲线跳高，证据不足。

第五步写有限结论。同一说话人若在不同自然语速下稳定改变2和3的比例，可说语速影响该位置实现ip的概率；不能说“快读一定没有句法边界”，因为句法边界从未消失。

### 5.2 例二 同一字串的普通窄焦点和纠正焦点

目标句候选：“阿爸勿欢喜姆妈个礼物。”

语境A问：“阿爸对姆妈个礼物啥态度？”回答更新的是态度，“勿欢喜”是普通窄焦点。

语境B先断言：“阿爸蛮欢喜姆妈个礼物，是伐？”回答用同一句纠正“欢喜”判断，“勿欢喜”是纠正焦点。

控制的关键是两次应答字串相同，尽量由同一说话人以匹配语速完成。这样焦点类型是主要改变因素。若一次用肯定句、一次用否定句，就无法知道差别来自否定词还是纠正功能。

观察不应只写“后面变低”。应逐个后续AP记录F0范围、相对调域位置、词汇目标是否仍可辨、是否有ip边界及是否因气声或喉化缺测。

- 若只是整体调域降低但内部目标关系保留，标`reduced`或register lowering。
- 若多个后续AP的词汇目标在可靠录音中中和，并经听辨支持，可讨论deaccenting或删调。
- 若F0跟踪因发声态中断，标`tracking_missing`，本条不能裁决删调。

这个例子同时检验S&S的MaP范围预测与Roberts的焦点类型差别，但同一结果对两套理论的意义不同，分析表中应分列。

### 5.3 例三 礼拜三中的词内对比

目标句候选：“伊礼拜三来上海。”

语境A问“伊哪日来”，整个“礼拜三”作为日期是新信息。语境B错误地说“伊礼拜四来”，回答纠正“三”。

端木式候选预测是：语境A可能为`(礼拜三)`，语境B可能为`(礼拜)(三)`。但实验不能把该候选直接写入TextGrid。标注者要独立检查“三”前是否有AP边界、“三”是否出现新的域首目标、是否仅有时长或强度增加。

可能结果一：多个日期和其他词族中，纠正非首语素都稳定新增AP，支持“突出可重组低层域”。

可能结果二：两种语境都保持一个AP，纠正时整个词的调域扩大，说明焦点不必通过拆域实现。

可能结果三：日期词拆域，高度词汇化词不拆，说明规则需要词内结构或词汇化条件。任何一种结果都比“焦点有影响”更具体。

### 5.4 例四 问句末端不是见问号就升

候选材料：“伊来过上海”“伊来过上海伐”“伊阿是来过上海”。三句分别作为陈述、助词是非问和正反问的起点，正式录音前需母语者确认自然度。

先标末AP的词汇调和长度，再标IP末端事件。若助词问句常出现H%，正反问常为%，说明不同问句类型不能共用一条“问号转升调”规则。

还要防止助词混淆。第二句多了一个音节，末端变化可能来自“伐”的词汇读音、AP长度或H%。理想设计应补充同字串不同功能和不同末词同功能的交叉材料。主实验若做不到，只能对“整种句式组合”下结论。

若一个短AP的La被H%覆盖，曲线上可能看不到预期低尾；较长AP中La可能提前，为H%留下实现时间。看不见La不等于词汇调类记错，也不等于AP消失。

### 5.5 例五 动补与后果小句

教学候选A：“伊推开门。”候选B：“伊推门，门开了。”候选C：“伊推勿开门。”

A中的“开”可分析为结果补语，B中的第二个“门开了”是一个有独立主谓关系的小句，C是潜能结构候选。表面都有“推、开、门”相关成分，但局部句法不同。

初步观察位置包括A的“推｜开”、B的“门｜门”和C的“推｜勿｜开”。如果B比A更常出现高层边界，不能只凭这一对证明“小句造成边界”，因为B更长且重复了“门”。正式材料需要匹配长度、词项、语境和说话人。

这个例子说明构式研究不是给每种句法结构指定固定分域，而是建立能排除替代解释的句族。

## 6 九层标注究竟怎样协作

### 6.1 A至I是信息模块 不是九条Praat轨道

项目九层如下：

| 层 | 核心问题 | 典型内容 | 主要存储 |
|---|---|---|---|
| A 音频与元数据 | 这是谁在什么条件下说的 | 音频、来源、说话人、时长、split | wav与metadata |
| B 音节与读音 | 每个音节在哪里 怎样读 | 起止、汉字、IPA、传统调类 | TextGrid与JSON |
| C 词法 | 哪些音节组成词或语素 | 词界、词性、构词、词汇化 | JSON 可配word轨道 |
| D 局部句法 | 相邻成分是什么关系 | NP、VP、动宾、动补、体貌 | 结构JSON |
| E 全句句法 | 小句怎样嵌套和组织 | 条件、主句、话题、关系小句 | 树或跨度JSON |
| F AP和低层域 | 哪些音节共同变调 | AP区间、边界、置信度 | AP轨道与JSON |
| G 音高事件和测量 | 有哪些目标 实际怎样实现 | H*、La、H%、F0、时长 | tones轨道与声学表 |
| H ip IP和Break | 边界有多强 | Break 0至4、ip、IP和证据 | breaks轨道与JSON |
| I 语境与表达功能 | 说话人在完成什么话语任务 | 焦点、问句、语速、情绪、诱导成功 | JSON与misc |

Praat中建议只开`syllable、word、AP、tones、breaks、misc`等约六条轨道。长句法树、语境和元数据放JSON，通过同一`utterance_id`与时间或音节跨度对齐。把九层全塞进TextGrid会让轨道拥挤，也不利于树结构存储。

### 6.2 为什么先修B层再动后续层

后续层都依赖音节索引。如果ASR漏掉“就”，原九音节变八音节，C层词跨度、E层小句范围和F层AP区间都会错位。正确流程是先修转写和音节边界，再重新导出结构对齐；不能只手工平移某一层标签。

### 6.3 什么是半开区间

程序使用从0开始的半开区间`[start,end)`：包含start，不包含end。例如“假使”占音节索引0和1，写`[0,2)`；下一个“伊”从2开始，写`[2,3)`。这样相邻区间首尾正好相接，长度等于`end-start`。

人类说明中若写“第1至第4音节”，那是一基闭区间。正式JSON禁止两套坐标混存；文档展示必须明确是哪一种。

### 6.4 一个九层示例的逻辑依赖

以U_DEMO_001为例，建议按以下顺序工作：

1. A层确认这是假数据，`source=demonstration`、`split=excluded`。
2. B层确认九个音节及时间，没有真实音频就把IPA写UNK。
3. C层从文本和词典建立词跨度。
4. D、E层依据释义建立局部关系和全句结构，不看F层答案。
5. F、G、H层由语音标注者依据录音建立候选和证据。
6. I层比较提示意图与实际表达，记录`elicitation_success`。
7. 裁决后才把可靠标签放入`adjudicated`，原始分歧仍保留。

这个顺序防止教学示例进入训练，也防止结构标注者用目标音频反向改树。

## 7 模型和数据文件里的工程缩写

### 7.1 L0至L4是输入信息消融等级

`L`在这里指information level或输入信息层级，不是音高低目标L。编号描述模型能看到多少结构信息：

| 等级 | 模型可见信息 | 典型问题 |
|---|---|---|
| L0 | 纯文本或字／音节序列 | 不加语言学知识能到什么程度 |
| L1 | 加词界或词法基本信息 | 词切分是否有增益 |
| L2 | 加词性和构词信息 | 功能词、词汇化是否有增益 |
| L3 | 加局部句法和构式 | 动宾、动补、数量等是否有增益 |
| L4 | 加全句结构和嵌入关系 | 长距离结构是否有增益 |

L0至L4是模型输入的比较条件，不是九层标注，也不是理论发展阶段。若在报告中写“L2效果变好”，必须说明是相对哪个基线、在哪个测试集、预测哪一层输出。

### 7.2 B0至B5是基线系统

`B`在03号文档中指baseline，基线模型；它与Break的B不是同一符号。现行基线包括：

- `B0`：只用文本。
- `B1`：文本加L2词法信息。
- `B2`：文本加L3局部句法。
- `B3`：文本加L4全句结构。
- `B4`：再加入语境焦点和语速等可用信息。
- `B5`：人工结构上限，用来测结构信息本身的价值，不是可直接部署的系统。

B0至B5是系统名称，L0至L4是信息输入等级；二者可以有关联但不能互换。例如B2通常对应文本加局部结构，却不等于所有实验都必须把它命名为L3。

### 7.3 T1至T3是任务分解

`T`在03号文档中指task，任务：

| 任务 | 英文全称 | 输入与输出 |
|---|---|---|
| T1 | text structure labeling | 从字／音节和词典信息预测词边界、词性、局部和全句结构 |
| T2 | structure to prosody | 从文本结构、调类、焦点、语速等预测AP、ip、IP、Break和AM事件 |
| T3 | F0 and TTS front end | 给定读音与韵律事件，预测连续F0、时长或测试TTS前端 |

T1不是调类T1，T2也不是传统声调T2。数据字段应使用`task_T1`、`citation_tone_T2`等不含歧义的名字。

### 7.4 BIO是什么

`BIO`是词或构词序列标注编码：`B`表示Begin，实体或词的开始；`I`表示Inside，内部；`O`表示Outside，不属于目标跨度。比如把“姆妈个礼物”切成“姆妈／个／礼物”，可给每个音节一串B-I-O标签，但实际标签方案要先明确是标词、语素还是句法span。

BIO适合平面序列，不足以单独表示嵌套关系和树。因此T1可用BIO预测词界，D、E层仍要保存跨度树；不能把BIO标签当完整句法分析。

### 7.5 CRF和BiLSTM

`CRF`是`Conditional Random Field`，条件随机场。它在序列标注时同时考虑相邻标签是否合法，例如不让一个I标签无故出现在B之前。`BiLSTM`是`Bidirectional Long Short-Term Memory`，双向长短期记忆网络；它从左右两个方向读取序列，生成每个字或音节的上下文表示。

`BiLSTM-CRF`是把上下文编码器和序列标签约束组合起来的模型。它不是本项目的理论，也不能因为它预测边界较准就证明某种句法规则。

### 7.6 Transformer和embedding

`Transformer`是利用注意力机制建模序列关系的神经网络架构。`embedding`是把字、音节、词性或说话人类别转换成向量表示。项目建议先用小模型和固定参数，避免低资源条件下把大模型记忆训练句当作结构泛化。

如果输入了说话人向量，测试说话人必须在训练折外；否则模型可能记住某个说话人的整体音高和分域习惯，造成虚假的泛化。

### 7.7 F1 Accuracy和Top k

`F1`是精确率Precision和召回率Recall的调和平均：

`F1 = 2 × Precision × Recall ÷ (Precision + Recall)`

精确率问“模型报出的边界有多少是真的”，召回率问“真实边界有多少被找到了”。F1适合边界检测，但必须先定义音节位置容差和不确定标签处理。

`Accuracy`是总体正确比例；类别不平衡时，全部预测成“无边界”也可能得到看似不错的Accuracy，所以不能只报Accuracy。

`Top-k coverage`表示把概率最高的k个候选保留时，真实标注有多少次落在候选集合里。对于同一句有多个自然读法的项目，Top-k比强迫唯一答案更能反映候选覆盖，但候选太多也会虚高，必须同时报告候选数量和不合理候选率。

### 7.8 RMSE和F0评价

`RMSE`是`Root Mean Squared Error`，均方根误差。T3中可用它衡量预测F0与真实F0的平均距离，但F0误差小不代表边界和焦点标签正确，也不代表听感更自然。

连续F0评价至少分开看：数值误差、曲线相关、目标对齐误差和听辨自然度。测试时不能把目标录音实际F0或时长作为文本前端的已知输入，这会泄漏答案。

### 7.9 ASR TTS和Praat

- `ASR`是`Automatic Speech Recognition`，自动语音识别。ASR可以给出粗转写和候选边界，但漏一个字会使后续音节索引错位，必须人工修B层。
- `TTS`是`Text To Speech`，文本转语音。本项目假设给对读音和韵律输入后，现有TTS能读好；研究重点是前端预测，不是重建整个声学模型。
- `Praat`是语音分析软件，用于看波形、频谱、Pitch和TextGrid并导出测量。
- `TextGrid`是Praat的分层标注文件，可保存区间层和点层。
- `JSON`是结构化文本格式，项目用它保存句法树、元数据、证据和不确定性；它不是音频文件。
- `CSV`是逗号分隔表格，适合批量声学测量和模型输入；它不能替代原始wav、TextGrid或裁决记录。

### 7.10 IPA Hz NA和UNK

`IPA`是`International Phonetic Alphabet`，国际音标，用于记录可复核的语音形式；不确定时写UNK而不是凭汉字猜。

`Hz`是赫兹，F0的频率单位。

`NA`是`not available`，表示该测量本应有但当前不可用，例如F0跟踪失败；`UNK`是`unknown`，表示标签或知识尚未确定。二者都不是零值，也不能混用。建议把`missing_reason`另记为`tracking_missing、noise、not_annotated`等。

### 7.11 metadata split source和hash

`metadata`是描述数据来源和条件的元数据；`split`是训练、开发或测试划分；`source`是自然会话、人工录音或电视剧等来源；`hash`是文件内容摘要，用于确认音频或词典版本未被悄悄替换。

`train/dev/test`分别常译训练集、开发集、测试集。开发集可以用于调参数；最终测试集一旦冻结，规则、词典、parser和模型配置不能读取它的人工标签。

## 8 新成员的实际工作清单

### 8.1 听一条录音前

先确认`utterance_id、speaker_id、source、sentence_family、condition、split`。确认自己读到的是当前版本文本，而不是旧转写或机器生成句。若没有母语者确认的读音，B层允许UNK；不要为了让表格完整而猜IPA或调类。

### 8.2 标一条录音时

1. 先完整听一遍，不急着看F0，也不先看理论预测。
2. 修正B层逐音节边界和文本。
3. 依据文本、释义和独立词法证据完成C层。
4. 依据结构而不是声调曲线完成D、E层；拿不准就写候选或UNK并备注理由。
5. F层先标AP候选和置信度，不把词界复制成AP界。
6. G层分别记录音高事件和声学测量；F0缺失写NA。
7. H层先记Break候选和证据，再决定是否升级为ip或IP。
8. I层同时保存提示焦点和实际表达，记录诱导是否成功。

### 8.3 标完一条录音后

检查区间是否相邻且不倒置，C至I层是否引用同一音节坐标，TextGrid和JSON中的ID是否一致。检查有没有把逗号直接变成Break 3、把最高F0直接变成焦点、把弱化写成删除、把喉塞或静音直接当成ip。

双标必须先独立完成。裁决稿是新版本，不覆盖两份原始标注；分歧本身是研究数据，可以帮助修改手册和估计一致性。

### 8.4 送进模型前

确认小试句族仍标为开发集，未见句族和未见说话人没有泄漏；确认训练输入没有使用测试录音的真实F0、时长或人工边界；确认不确定标签有掩码策略；确认报告能区分人工结构上限、自动parser结构和纯文本基线。

## 9 常见误读对照表

| 直觉式说法 | 问题在哪里 | 更好的写法 |
|---|---|---|
| 有逗号所以这里是ip | 标点不是韵律证据 | 该处有句法小句交界；ip需用听感和声学证据检验 |
| 0.12秒静音就是边界 | 静音可能来自犹豫、换气或录音切断 | 记录pause_ms，并独立判断Break和ip |
| F0最高的字就是焦点 | AP起始扩展、调类和性别都能抬高F0 | 用问答语境、同人对照和多种声学线索判断焦点 |
| 后焦点变低就是删调 | 降低可能保留词汇目标，或只是F0跟踪失败 | 区分lowering、compression、deaccenting和tracking_missing |
| 看到AP就按形容词短语处理 | 本项目AP是Accentual Phrase | 句法形容词短语写AdjP，韵律单位写AP |
| T2模型比T1好，说明T2调类正确 | 任务编号和调类编号同名 | 明确写task_T2或citation_tone_T2 |
| 端木例子证明焦点必拆域 | 单个例子不能推出无条件规则，且有全词扩展的反向证据 | 写“该词族和语境下检验焦点驱动重组” |
| Roberts图的曲线就是所有上海话标准 | 图例是特定说话人和材料 | 写“论文中的一次分析／本项目候选”，不预填gold |
| 词界、AP界、ip界和停顿都用一条竖线 | 四者层级和证据不同 | 分别保存C、F、H层及pause_ms |
| 把不确定的2m改成2方便训练 | 牺牲真实不确定性会虚高准确率 | 保留2m，主损失屏蔽或另作不确定子集 |
| 只报F1最高的模型 | 可能只在开发集或已见句族记忆 | 同时报分层区间、Top-k、完全匹配和泄漏审计 |

## 10 从jieba旧笔记迁移什么 不能迁移什么

旧笔记主要在`../jieba/legacy/backups/claude.md`以及`../jieba/docs/`下的文献和变调研究笔记。它们对词性、方言词形、四五字组、焦点和文献线索很有用，但不是AM项目当前的gold手册。

### 可以迁移为候选或背景

- `va`可提示动词后的结果／状态补语候选；`vn`可提示词汇化动宾候选。
- `a`与`va`的区分提醒我们：同一个汉字在谓语和补语位置可能有不同读音或变调行为。
- `勿`在动词前、动词后或固定结构中的身份需要分别审阅，不能只按字形统一标签。
- 四字、五字组的“一四、二三、三二”等历史分式可作为材料设计线索，但“广用式／窄用式”是旧文献术语，不能和实验语用学的广焦点／窄焦点混用。
- `GENERATIVE_PROSODY_THEORY_REVIEW_20260908.md`总结了S&S、端木、Roberts、Sun与Chen、Match和PENTA的证据范围，可作文献入口。

### 不能直接迁移为确定规则

- 旧分词标签不自动等于C、D层当前句法分析。
- 旧笔记中的一条字串或一次音频读法不能直接成为所有说话人的AP、ip或IP答案。
- 绍兴话或普通话的数量、轻声、概数例子只能提供比较线索，不是上海话录音标签。
- 论文图中写“的”的正字、旧转写“无没／没”等要保留原文与规范文本对应，不应无记录替换。
- 旧模型输出、机器预标和自动F0不能进入自然语音gold。

迁移的正确格式是：保留`legacy_label`、来源文件、原句和释义；另建当前`normalized_label`、审阅者、日期和不确定性。若旧标签与当前项目冲突，优先暂停进入adjudicated，并在错误表中记录冲突原因。

## 11 读完后的自测题

1. 在“假使伊来，小李就要走”中，为什么“来”后可以是Break 2也可以是3，而句法树不必改变？请分别说出低层AP和高层ip的证据。
2. `H*`和`H%`各自关联什么位置？为什么不能都翻译成“升调”？
3. “阿爸勿欢喜姆妈个礼物”的普通窄焦点和纠正焦点怎样控制字串不变？观察到整体变低时，哪些额外证据才能讨论删调？
4. 解释`[0,2)`为什么不包含索引2；再说明“小李”怎样同时是一个C层词和两个B层音节。
5. L3、T2、B4、F1各自属于什么编号系统？任选两个说明混写会造成什么错误。
6. 如果模型把“来”的实际时长作为输入来预测“来”后边界，为什么这是目标音频泄漏？怎样改成文本前端可用的变量？

自测合格标准不是背出所有缩写，而是能在新句上明确写出：我现在标的是哪一层、证据来自哪里、还缺什么、哪一种替代解释仍未排除。
