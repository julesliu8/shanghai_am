# 五度标记与 F0 归一化：方法、公式和本轮约定

记录日期：2026-09-10。本文是录音 11 音轨 1 五度声学预标注试验的方法依据。实测阈值与提取参数保存于 `data/metadata/recording_11_track1_tone_normalization.json`，结果见音轨1试验报告（本地材料：`12_音轨1五度标记试验报告.md`）。网页、论文和提取文本缓存在 `generated/recording_11_20260909/tone_pilot/references/`。正式音频索引仍为 `data/metadata/recording_11_segments.csv`。

本轮采用：**在整个音轨 1 的合格有声帧上，在 log F0 域计算 P5/P95，再用对数极差 T 值分成五档。** 输出属于可复查的自动声学估计；说话人分离、音节边界与听辨调值尚未全部人工确认。这里的归一化只变换测量数字，不改变录音音高、语速或音量。

## 1. 五度标记表达什么

赵元任五度调值以 1、2、3、4、5 表示正常调域中由低到高的相对音高。`55` 表示高平，`51` 表示高降，`35` 表示升，`214` 表示降后升。数字之间的顺序表示音节内部的时间顺序，不能把 `214` 读成一个三位数，也不能把五度数字当作声调类别编号。

Rose（2014，第 101–102 页）说明：赵元任原来的刻度是五个等间距音高位置，即将调域分成四个间隔；没有规定全人类共用的 Hz 边界，也没有要求任何语料都占满固定的八个半音。五度刻度是转写方式，从连续 F0 到这些符号还需要确定调域、采样位置、量化规则与听辨依据。[1]

F0 是声带振动周期的声学估计，pitch 是音高知觉，两者相关但不等同。Rose 对温州文成话和粤语的分析显示，一些实际音高目标落在相邻整数之间。离散成五档会损失信息，不能将机器输出当作唯一正确的听辨答案。[1]

上海话连续口语中，词汇本调、变调后的表面调值、句中语调、语气和发声态还要区分。按一个字的 F0 输出 `31`，只表示本轮尺度下该时段大致下降；不据此宣布这个字的字典本调是 `31`，也不据此自动产生 AP 边界。

## 2. 常用尺度和归一化方法

设有效有声帧基频为 \(F_i>0\)，单位 Hz；参考语料必须先确定说话人或轨道范围。无声帧、缺测和不能确认的跟踪值不参与计算。

| 方法 | 公式或核心操作 | 用途和限制 |
|---|---|---|
| Hz 原值 | \(F_i\) | 保留物理量；同样 20 Hz 的差在 100 Hz 和 300 Hz 附近不具有相同相对音程。 |
| 半音 | \(s_i=12\log_2(F_i/F_{ref})\) | 倍频相差 12 半音。固定参考值只是换尺度；按说话人选参考值还能平移调域，但不会自动缩放调域宽度。 |
| 线性极差 FOR | \(u_i=(F_i-L)/(H-L)\) | 映到相对范围；Hz 等距分档不是对数等距分档。 |
| 对数极差 LD | \(u_i=(\log F_i-\log L)/(\log H-\log L)\) | 以相对音程等距；各档在 Hz 中的宽度不同。 |
| 对数极差 T 值 | \(T_i=5u_i\) | 连续范围为 0–5，再按约定量化成整数 1–5。不是先映到 1–5 后四舍五入。 |
| Hz z-score | \(z_i=(F_i-\mu_F)/\sigma_F\) | 用说话人的均值和标准差标准化，无固定上下界。 |
| log F0 z-score / LZ | \(z_i=(\log F_i-\mu_{\log F})/\sigma_{\log F}\) | 适合比较或统计建模；z=1 表示高于均值一个标准差，不等于五度值 1。 |
| 稳健分位数端点 | 用 P5/P95 等分位数替代原始最小值/最大值 | 减少极少数尖峰决定全尺度的问题；分位数选择是额外参数，不能当作已统一的五度国际标准。 |

半音公式中的 \(F_{ref}\) 可用固定 100 Hz，也可用同一说话人参考材料的均值或中位数，但必须记录。用均值和用中位数是不同实现。Nolan（2003）的语调模仿实验中，半音与 ERB 尺度较好反映受试者对语调跨度等效的判断；这是采用对数尺度的实证依据之一，不表示所有音高知觉任务都只有这一种最佳尺度。[2]

Zhang（2018）第 826–827 页逐项给出 FOR、对数极差、T 值、z-score、LZ 和半音等公式。该研究的无锡话与松江话材料中，以每位说话人平均 F0 为参照的半音尺度较好保留社会语言学变异；因此，不应笼统声称极差归一化总比其他方法更科学。方法的选择取决于要比较调类、调域，还是年龄和地域差异。[3]

z-score 是一般统计标准化。本笔记使用语音 F0 文献中的 z-score/LZ 称谓，不将元音共振峰研究中的 Lobanov 名称直接当成已验证的 F0 五度换算标准。标准差按总体还是样本计算也应记录（分别对应常见软件的 `ddof=0` 和 `ddof=1`），不能在重跑间更改而不留痕。

### T 值与“石锋法”的文献口径

汉语实验声调文献中常见的对数极差 T 值公式为：

\[
T_i=5\frac{\log F_i-\log F_{min}}{\log F_{max}-\log F_{min}}.
\]

Zhang（2018，第 826 页，式 7）明确给出此式，正文归于 Shi and Wang（2006），并说明它使用每位说话人的 F0 极值。本轮通过这篇可读取全文的综述核验公式，属于对通常所称“石锋 T 值法”的二手核验；没有把未读到的石锋早期原作写成已核实的一手出处。[3]

Li、Liu 与 Chiang（2024，第 712 页）也概述了把说话人最小和最大 log F0 映到 0 与 5 的方法，但其参考文献将来源列作 C. Shih 的 1986 年技术报告。作者拼写和引文有歧义，本笔记不据它认定石锋原始发表年代。该文可用于提示连续语音中的协同发音、语调位置与声学跟踪困难，不能用于消除这一书目疑点。[4]

## 3. 本轮怎样把 T 值变成五档

先计算连续值，随后截断到 0–5：

\[
T_i^{raw}=5\frac{\ln F_i-a}{b-a},\qquad
T_i^{clip}=\min(5,\max(0,T_i^{raw})).
\]

采用 Zhang（2018，第 826 页）所述左闭分档：0 至不足 1 为 1 档，1 至不足 2 为 2 档，依次类推；最高端点 5 并入 5 档。[3]

\[
q_i=\min(5,\max(1,\lfloor T_i^{clip}\rfloor+1)).
\]

| 连续 T 值 | 输出五度整数 |
|---|---:|
| \([0,1)\) | 1 |
| \([1,2)\) | 2 |
| \([2,3)\) | 3 |
| \([3,4)\) | 4 |
| \([4,5]\) | 5 |

`ceil(T)` 并限制为 1–5 是另一种右闭分档实现：\([0,1]\)、\((1,2]\) 等。它与本轮方案只在恰好为整数的内部边界 \(T=1,2,3,4\) 不同；例如 T=2 在本轮为 3 档，在 ceil 方案为 2 档。两种实现必须明确端点，不能声称完全等价。**本轮不用 ceil。**

下列方案则与 T 值五等宽分档在大量区间内都不同：

\[
y=1+4u,\qquad q'=\operatorname{round}(y).
\]

它把 1–5 看成五个等距目标位置，按最近位置分配，内部边界在 \(u=0.125,0.375,0.625,0.875\)；T 值分档的内部边界在 \(u=0.2,0.4,0.6,0.8\)。例如 u=0.15 时，T 值分档输出 1，最近目标法输出 2。二者可服务不同描述目的，但不能只换函数名称而混用同一份阈值表；四舍五入还须指定 ties-to-even 或 half-up 等规则。

缺测不能经上述公式变成 1 档。只有有效正 F0 才进入换算；NaN、无声或不可信测量保留为空并给质量标记。

## 4. 整轨归一化与 Hz 边界计算

### 4.1 先在 log 域计算稳健端点

令 \(\mathcal V\) 为音轨 1 全时长内通过本轮声学质量筛选的有声帧集合：

\[
x_i=\ln F_i,\quad i\in\mathcal V;
\qquad a=Q_{0.05}(x),\quad b=Q_{0.95}(x).
\]

\[
L=e^a,\qquad H=e^b.
\]

实现固定为 NumPy `quantile(log_f0, [0.05, 0.95], method="linear")`。对有限样本的分位数采用插值时，“先求 Hz 分位数再取 log”和“先取 log 再求分位数”可能略有差异；本轮使用后者，随后指数变换回 Hz。若 \(b\le a\) 或有效帧不足，归一化失败，应报告缺测，不能除以零或输出假轮廓。

对数底数可以为 e、2 或 10，只要分子分母一致。半音 \(s=12\log_2(F/F_{ref})\) 是 log F0 的仿射变换，因此对同一批帧、同一分位数插值规则，在半音域归一化与本轮 log 域公式等价。

**P5/P95 是本轮稳健化工程选择，并非原始极值法的原样复制。** 同时保存有效帧的 min/max 版本作为敏感性对照。两者都不能消除大量倍频错误、说话人混合或语态变化。落在 P5 以下或 P95 以上的真实有声帧仍保留原 Hz 和未截断 T，只在五度显示中饱和为 1 或 5，并记录越界标记；不能把这些点全部称为错误值。

### 4.2 从对数边界反推 Hz

五档的六个边界为：

\[
B_k=\exp\left(a+\frac{k}{5}(b-a)\right)
=L\left(\frac{H}{L}\right)^{k/5},\quad k=0,1,\ldots,5.
\]

正常参考范围内，各档为 \([B_0,B_1)\)、\([B_1,B_2)\)、\([B_2,B_3)\)、\([B_3,B_4)\)、\([B_4,B_5]\)。低于 B0 和高于 B5 的合格帧分别饱和到 1 与 5，但带越界标记。展示表可以保留两位小数，实际分类必须使用未舍入边界。

数值实现使用 `np.searchsorted(boundaries_hz[1:-1], f0, side="right") + 1`，与上述左闭五档相同。原因是直接对浮点log运算的T再floor，在理论T=1的边界可能得到0.999999999999997而错分低一档。脚本已检查各精确边界及其紧邻较小浮点数；该数值处理不改变理论分档公式。

仅作公式示例：若 L=100 Hz、H=200 Hz，则六个边界约为 100.00、114.87、131.95、151.57、174.11、200.00 Hz。此例不是录音 11 的测量结果。五档在对数/半音空间等宽，在 Hz 空间越来越宽。

### 4.3 “整个音轨”不等于“同一说话人”

本轮按用户要求，以整条音轨 1 为归一化范围，但必须记录 `normalization_scope=track1_whole_recording` 和说话人未完全确认的状态。一个麦克风可能录到多个人、远处应答或另一人的串音；反过来，同一个人也可能同时出现在两条轨道。轨道号不能当成说话人 ID。

同一人也可能有低声、笑声、模仿他人、兴奋语气、气声和喉化等不同语态，60 分钟内调域不一定恒定。整轨范围适合作为本轮统一参照，不表示固定生理音域。若后续确认多个说话人，应按“说话人 × 录音批次”重估；若研究语态差异，应先决定要保留还是消除这种差异，再设计分层参照。不能为让某个字符合预期调值而逐字调整上下界。

此外，全轨等时间步长采样意味着较长的有声部分贡献更多参考帧，并非每字等权。记录被筛掉的时间、帧数和原因；不要把没有转写的音频自动视为静音。本次用户修改稿删掉的文字，也不等于该时刻不存在真实声音。

## 5. 从音频到五度轮廓的流程

1. **确认输入与时间线。** 根据 Audition 工程和录音元数据识别音轨 1，恢复原始工程时间位置。核对采样率、声道、文件哈希和时长。幅度归一化与 F0 归一化分开记录，原文件保持不变。
2. **以宽范围试提取，再检查。** 使用 Praat 或 Parselmouth 提取 F0；算法、版本、时间步长、pitch floor、ceiling/top、清浊阈值等全部入参数文件。本轮主处理流程先检查 50–600 Hz 宽范围结果，再依据实际分布和候选片段判断参数，不按听起来“男/女声”就直接锁死范围。
3. **保存原测量和筛选掩码。** 至少保留时间、原 F0、选中候选的周期性强度和排除原因。Praat 候选 strength 是周期性指标，不是字音正确率，也不是经过校准的正确概率。[5]
4. **检查半频、倍频和非语音。** 对接近一倍频程的跳变、floor/ceiling 附近堆积、短有声孤岛、笑声、背景声及两人重叠标记复核。不能只因一次跳变就自动折半/翻倍：真实大跳也可能存在。清音和声门不规则段不强行填平。
5. **用整轨合格帧固定参数。** 计算 log F0 的 P5/P95、min/max 对照、半音跨度和上述 Hz 边界，保存独立参数文件。同一轮所有试验片段共用此尺度；每个片段单独归一化会消除片段间真实高低差。
6. **在音节/字候选区间测量。** 对齐边界内按相对时间抽取起、中、末或更多位置的稳健局部 F0。邻域没有足够有声帧就缺测，不越过长静音、清音或相邻字去借点。所有采样点比例、邻域宽度、最少帧数和有效比例门槛由处理脚本记录。
7. **输出连续值与离散串。** 保存采样的 Hz、未截断 T、档位和完整序列。例如五点序列 `33421` 是测量摘要；压缩为 `3421` 只是便于看走势。若写成传统两三数字的调值，还要检查真正的起点、转折与终点，不把任意三等分自动称作三个调目标。
8. **分层复核。** 对照波形、频谱、F0 和听感分别确认字边界与音高跟踪。先标 `machine_draft` / `review_pending`；完成并记录人工核验后才改为对应的 `human_verified` 状态。

Praat 官方目前将 filtered autocorrelation 列为语调和声带振动的主要方法，同时保留 raw autocorrelation 与 raw cross-correlation 等算法。不同算法和版本的结果不一定相同。不能将一个算法的原值和另一个算法的清理后值无记录拼成“同一条曲线”。具体本机操作与可重跑命令见本轮独立工具笔记。[5]

## 6. 如何用时间位置把五度标记与汉字匹配

字幕的句级时间只确定大范围，不能推出每字时刻。先用用户修订文字对对应原音频进行强制对齐，再把得到的字/词候选边界用于选取 F0。模型有输出不等于上海话音节边界可靠，尤其当训练语言与方言差别较大时。

句片段中的相对时间须转换回全轨坐标：

\[
t_{global}=t_{clip\_origin}+t_{local}.
\]

`clip_origin` 必须取物理音频实际切出起点。已有句切片带前后各 50 ms 上下文，因此不能直接把字幕 start 当成切片 0 秒；录音最前端的 padding 还可能被裁掉，应读取索引中的实际切片起点。用全轨坐标完成连接后再转换回 TextGrid 的局部时间。

对字候选区间 \([s_j,e_j)\)，按帧中心时间取：

\[
\mathcal V_j=\{i:s_j\le t_i<e_j,\ i\text{ 为合格有声帧}\}.
\]

最少保存 `utterance_id`、`char_index`、汉字、原文本来源、对齐方法、全轨与切片起止、有效帧数、候选五度序列、缺测/越界、说话人状态、时间对齐状态和五度复核状态。用稳定 ID 连接正式索引，不能用当前排序行号连接。

一个汉字通常对应一个音节，但连读省略、合音、儿化、语气词、重复、外语和数字可能破坏这种对应；标点不应分配 F0。对齐器若只给出多字词的共同区间，不能平均分时长冒充逐字强制对齐；可先输出词组轮廓，逐字层保留待定。若用户删掉一段实际说出的字，强制对齐可能把保留文字拉到错误位置，应标记删节/不匹配区间，不能擅自恢复删掉的文本。

若句文字来自两轨监听混合，而目标只测音轨 1，某些文字可能实际由音轨 2 的说话人发出。这类字在音轨 1 没有可靠 F0 时应标 `track_mismatch_or_unvoiced` 等待复核，而不是从邻近帧硬配一个调值。

## 7. 评估与当前限制

本轮完成的是“固定整轨参照 → 提取相对音高 → 用时间连接少量文字”的可复现试验，不是全录音人工调值标注。评价应报告：参考帧覆盖率、无声与排除比例、P5/P95 与 min/max 两种调域、越界饱和比例、可疑倍频跳变、每字缺测率、音频/文字不匹配数，以及已人工核验的数量。

只检查时间有序、文件存在或有声帧足够，不代表边界或五度值正确。接下来影响可靠性的主要问题是轨道内说话人归属、串音与重叠、气声/喉化/笑声跟踪、长录音语态变化、删节文字和方言强制对齐误差。应优先复核这些问题，再扩大到全部切片。

F0 和五度标记继续用于本项目的听校与声学质量控制。它们不自动转成 AP 金标准，也不作为面向合成前文本的 AP 预测模型输入，避免将录音后的信息泄漏到文本侧实验。
