# 近期任务清单

## 本周

- [ ] 确认12名中青年、4名年长者是否可招募，并记录成长地和日常上海话比例。
- [ ] 确认自然口语现有时长、版权和同意范围；目标收集至少60分钟。
- [ ] 两名语言学学生阅读Roberts §4.1至§4.7和第5章，用图31、32、30、38、60复述标注理由。
- [ ] 完成文献综述第一稿：Roberts、Selkirk & Shen、Duanmu、Sun & Chen、Match Theory、PENTA；分开事实、解释和未决问题。
- [ ] 按[现行验证卡](06_三套理论验证卡.md)先写四项小试材料：SS2与R2共享焦点实验、R1条件句、D1词内对比、R3句末事件；每项先审阅一个句族的三种条件，不得把论文汉字直接当上海话定稿。

## 第2周

- [ ] 由母语者审阅问答提示，确认普通窄焦点、纠正焦点、广焦点和三种问句自然。
- [ ] 初始化TextGrid和metadata模板，测试`syllable、word、AP、AM_tones、breaks、misc`层。
- [ ] 写Praat批量导出脚本：F0 20点、时长、边界前后F0、静音、语速；保留人工修改入口。
- [ ] 设定四名中青年小试排程，随机顺序和重复次数；录音设备和环境检查。

## 第3至4周

- [ ] 完成小试96条左右录音，双人标B至I层，第三人裁决疑难项。
- [ ] 计算各层标注一致性和平均耗时；修订标签说明，不把低一致性标签立即加入模型。
- [ ] 冻结v1 schema、词典快照和句族划分；把小试全部标记为开发集。

## 第5至8周

- [ ] 采集自然会话，优先获得可定位的叙述、问答和纠正片段；逐段记录来源和说话人。
- [ ] 按现行验证卡完成四项核心受控录音；每个核心项目保留全新词项和未见组合。
- [ ] 语言学组完成C至I层，计算机组完成F0候选、音频质量、近重复和split泄漏检查。
- [ ] 每周输出一页错误表：自然度、焦点诱导失败、F0跟踪失败、结构歧义、边界不确定。

## 第9至12周

- [ ] 训练B0至B5结构／韵律基线，按说话人、句族和来源封存验证。
- [ ] 建立人工结构上限与自动结构系统的差异表；报告边界Top-k覆盖及构式内收益。
- [ ] 进行固定时间的纯人工／AI辅助标注实验，独立质检后统计合格条数、返工率和每条耗时。
- [ ] 对《繁花》材料完成授权、场景、说话人和转写审查；无可靠信息的片段仅作域外人工测试。
- [ ] 锁定最终测试集，完成听辨、F0误差、结构F1和年龄组分析；撰写研究报告与TTS输入示例。
