# 变调界限预测近期任务清单

本清单按2026年9月9日确定的新范围执行：只研究低层变调域／AP界限预测。焦点、停顿、ip、IP、句末语调和连续F0暂缓。

## 本周

- [ ] 确认可招募的中青年人数、已有自然口语净时长、授权与同意范围。
- [ ] 冻结`AP_boundary`二分类定义：每个相邻音节位置标0或1，另允许`uncertain`。
- [ ] 从C01实词虚词、C02普通／词汇化动宾、C03动补、C05长词中各选若干自然句族。
- [ ] 由母语者审阅字词、读音和中性提示；删除刻意纠正、对比、问句句末和强停顿任务。
- [ ] 两名标注者试标20至30句，只判断音节、词、AP和排除原因。

## 第2至4周

- [ ] 建立`syllable、word、AP、misc`四轨TextGrid模板及对齐JSON。
- [ ] 完成约96条中性语境小试；同一句族的速度条件与重复全部进入开发集。
- [ ] 计算AP边界一致率、Precision／Recall／F1、每句完全一致率和`uncertain`比例。
- [ ] 修订边界证据说明；无法稳定裁决的构式暂不扩量。
- [ ] 冻结v1 schema、词典快照、句族表及训练／开发／测试分组。

## 第5至8周

- [ ] 收集至少60分钟有效自然口语目标材料，按说话人和会话关系分组。
- [ ] 标注C01至C08中审阅通过的结构，明显依赖焦点或含不流利停顿的样本转入`excluded_or_future`。
- [ ] 实现S&S低层实词边缘规则和端木非焦点音步／长度规则，保存逐边界触发日志。
- [ ] 建立L0至L4特征和BiLSTM／小型Transformer边界基线。
- [ ] 每周输出错误表：分词、读音、词汇化、结构歧义、域界不确定、排除原因和数据泄漏。

## 第9至12周

- [ ] 在未见句族、说话人和来源上比较L0至L4及理论规则。
- [ ] 报告边界Precision、Recall、F1、整句完全匹配、Top-k覆盖和不合理候选率。
- [ ] 比较人工结构上限与自动结构输入，区分知识价值和parser误差。
- [ ] 进行固定时间的纯人工／AI辅助AP标注实验，以独立质检合格条数和返工时间评价。
- [ ] 输出错误分析、可审计边界规则和TTS前端接口样例；不开展焦点、停顿或整句F0评价。

## 每次操作后检查

- [ ] 文件是否位于README规定的位置，原始、人工、生成和归档材料是否分开？
- [ ] 是否只把AP边界作为目标，没有偷偷加入焦点、停顿、ip/IP或句末语调标签？
- [ ] 是否把教学括号、理论预测、旧jieba标签或机器预标误当作gold？
- [ ] 是否按说话人、会话和句族防止训练测试泄漏？
- [ ] 是否记录`uncertain`和`excluded_or_future`，而非强行二选一？
- [ ] 是否更新README的项目状态、数据规模和当前问题？
