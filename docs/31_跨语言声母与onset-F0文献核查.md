# 跨语言声母类别与 onset F0：共性、差异与发声机制

更新：2026-09-14。本文整理既有项目文献和可核验的经典跨语言结论；不把跨语言平均效应直接移植为上海话校正值。

## 结论先行

“翘头”（声母释放后起始F0偏高、随后回落）是**常见的跨语言倾向**，尤其常见于清不送气塞音、送气塞音和部分清擦音之后；但它不是所有语言、所有音节位置或所有说话人的必然现象。方向和持续时间受声调、声母部位、VOT、发声态、语速、重音/变调域、元音和测量窗影响。浊音常见相反的F0降低（depressor effect），但也有语言把喉化、预喉化或浊音实现为复杂的非单调轨迹。

送气不等于“必然比不送气更高”。送气可能延长清音/喉部张力影响，使高起点持续更久；也可能因无声段、弱起声和F0不可测而造成选择偏差。擦音的影响取决于清浊、喉化、摩擦噪声与元音起声重叠，不能把/ɕ、s、h/统一标为送气。

## 语言证据的层级

| 类别 | 跨语言可重复倾向 | 不能概括的部分 |
|---|---|---|
| 清不送气塞音/塞擦音 | 释放后F0常高于浊音，随后向目标轨迹回归；汉语、越南语、泰语、部分非洲声调语言均有类似报告 | 高度依赖声调类别和音节位置；并非每个清音都出现可听翘头 |
| 送气塞音/塞擦音 | 常与更高或更晚稳定的起始F0、较长VOT/无声段共现；在有声调语言中可增强起始扰动 | 送气本身、VOT和起声缺测难分；有些语言送气与声调组合会重排或减弱效应 |
| 清擦音 | /s, ʃ, ɕ, h/之后可见高起点或F0延迟，主要取决于喉部张力和摩擦持续时间 | 噪声段常被F0算法误追；必须检查波形、周期和有效起声，而不能只看第一F0点 |
| 浊塞音/浊擦音 | 常见低起始F0或“depressor”效应；声带松弛、跨声门压较低是常用解释 | 浊音的真实声带振动、预喉化和语境实现并不一致，方向可反转或变成非单调曲线 |
| 无声/声调对立 | 同一声母效应会被目标声调、前后音节、焦点及变调域覆盖 | 将声母平均效应当作固定半音修正，会把音系目标和语音扰动混在一起 |

经典实验和综述通常以 Hombert、Ohala & Ewan 的 consonant–F0 interaction 框架、Ohde 的声学/生理研究、Kirby 与 Brunelle 等东南亚声调研究，以及汉语和吴语的声母—F0研究为基础。项目已核验的上海/吴语材料包括 Chen 2011、Shi, Bai & Chen 2024（[文献总表65、71](22_项目文献总表与引用规范.md#ref-65)）；项目方法依据见 Praat 手册[69](22_项目文献总表与引用规范.md#ref-69)。这些资料支持“条件化声母扰动”而非通用去翘头常数。

## 发声机理：合理但需区分的链条

1. **喉部构形与声带张力。** 清阻音释放前后，声带常较分离、张力较高；环甲肌张力和声带有效长度改变可使振动频率暂时升高。浊音则可能保持较松弛或喉化构形，产生较低F0。
2. **气流和跨声门压。** 送气提高口腔后续的气流需求并延迟规则振动；声门下压、声门开度和重新起振过程共同决定“何时有F0”和起振后的频率。高F0不必等于听者把它当作独立声调目标。
3. **VOT与测量选择。** 送气越长，前30–60ms可能没有可靠F0；留下来的第一帧天然偏向较晚且可能较高的周期。因此“送气组翘头更多”既可能是生理效应，也可能是可测性选择效应。
4. **辅音—元音协同发音。** 舌位、咽腔和元音的起始共振与喉部动作重叠；/i/的舌位和高前元音可能改变声道反馈、起振时刻及F0轨迹，但不能只凭F0把这些成分分开。
5. **感知与音系补偿。** 听者通常结合后续F0、时长、VOT、发声态和语境归因；因此一个高起点可以被听成辅音扰动而不是高调目标。只有当扰动稳定、足够长且与声调类别协同时，才可能进入音系化或调类线索。

## 对本项目的直接约束

本项目音轨1粗四组显示送气后的D较大，但同部位同韵母的/tɕʰi/与/tɕi/几乎相同；/i/＋送气主指标仅36字，介音＋送气仅8字。故当前最合理的机器规则是：记录起始高低、首次有声延迟、VOT/边界待核、算法一致性和声母类别，**不自动减去固定F0**。报告[30](30_音轨1_i与送气声母起始F0核查.md)的D是筛查指标，不是跨语言生理常数。

后续若要检验机制，应在同说话人、同调类/域位、同韵母和同部位的送气—不送气对立中同时测量VOT、起声延迟、F0斜率、H1*−H2*、谱倾斜和强度；把“没有F0”作为结果而不是删掉。优先做可比的`ch:c`、`th:t`、`tsh:ts`，并把擦音单列。
