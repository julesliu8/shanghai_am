# 三套理论的验证卡与假设结果

本文件默认读者已经掌握[本科生导读与术语例解](07_本科生导读与术语例解.md)中的AM符号、AP/ip/IP、句法缩写和实验基本逻辑。

本文件与学生学习文档配套。所有比例、差值和读法对照均为假设结果，专为说明怎样从数据得出结论，绝非已完成实验。实验句在录音前经母语者审阅，固定字串、词汇读音、结构、提示版本和随机顺序。理论不能通过给模型输入理论自身生成的答案来证明。

## 1 S&S的验证

### SS1 实词边缘与虚词附着

命题：低层域左边缘与实词左边缘对应，虚词常附着，较高层约束可阻断附着。范围为S&S原章p.320及相关分析，不是无例外的“凡虚词必粘左”。

材料：候选“老师买仔书”“老师买书”“老师买仔搿本书”，再换成“阿姐看仔报纸”等独立句族。主要观察体貌标记是否并入前一动词域，后续实词是否起域。三句长短不同，作为附着的组合检查；正式比较在更多词族中匹配长度，并将长度纳入分析。体貌仔的实际用法先审阅，避免普通话结构套方言。

操作：结构标注者只看文本与释义，冻结N/V及功能词身份；按原规则产生每个可检边缘的预测并留日志；语音标注者先不看理论边界。只在双方确定该规则适用的位置统计命中，并另报总体覆盖。

假设结果A：“买仔”在不同词族多数同域，而“书”多起新域，条件稳定。结论：支持该低层映射在所测构式的默认价值，尚不能支持高层MaP分析。

假设结果B：“买仔”只在慢读拆开，舒适读多合。结论：严格确定性版本不足，需要加入节律或风格条件；不能把慢读样本全部剔除保住规则。

假设结果C：“仔”被读成另一个功能或句子不自然。结论：材料／结构无效，不算理论反证，应修订开发材料而不修改封存测试。

### SS2 词汇最大投射是否截断焦点后作用

命题：给定S&S对句子的独立结构分析，MaP限制相关焦点后删调范围。目标“阿爸勿欢喜姆妈个礼物”，焦点在“勿欢喜”，宾语NP从“姆妈”开始。Roberts图30提供反证线索，但本实验用同一个字串跨焦点条件控制。

条件：广焦点、普通窄焦点、纠正焦点各两遍。问答分别谈整件事、询问态度、错误断言“欢喜”后被纠正。每个句族都保留相同目标应答，不将否定句与肯定句直接比较。

测量：后焦点各AP的调域中位位置、范围、目标对齐、词汇音高事件可辨性，以及独立听感强边界。后续宾语跨NP的弱化范围是主要结果；焦点自身音高增加只证明操纵是否起效。

假设结果A：纠正条件中“姆妈个礼物”仍稳定呈现其词汇目标，而范围在NP边缘恢复，重复和新词族一致。结论：支持S&S该位置的限制，削弱R关于此条件容易跨NP去重音的推广；仍需区别有无ip以及实际语境。

假设结果B：纠正条件中宾语多个AP的词汇目标不可辨，普通窄焦点仍保留；听辨确认两条件意图不同。结论：挑战S&S该句法边缘的强范围预测，支持R的焦点类型区别。若只有单一说话人出现，结论限于个体。

假设结果C：两条件都仅降低4半音、范围和目标保持。结论：观察到语音降低，不能叫作音系删调；对S&S删调假说尚无充分裁决。4半音为示意数字。

假设结果D：目标不见但全段气声／喉化导致F0缺失。结论：测量不足，不是删调证据；须听辨、频谱及可追踪片段交叉确认。

### SS3 高层是否必须在嵌入边缘迫使低层断开

材料以图28、29“就是我根本无没辰光”的结构为出发点。先固定同一文本和句法树，并由理论实施者写明为何“我”前预测较高层边缘、从而迫使低层断开；若树与映射并不能得出这一强制预测，该位置不进入此项反证统计。

假设“(就是)(我)”与“(就是我)”在同人、同语境的自然读法中均出现，后者还保留跨边缘同域的语音证据。结论：挑战该冻结结构下的强制分割，而不是证明句法完全无用。若“合域”只是两个AP的音高弱化，边界听感仍存在，则应转入R的跨AP互动解释，不计强制边界消失。

## 2 D的验证

### D1 非首语素的对比能否重组变调域

命题：词内新增突出位置可能形成新域，原文例为“老虎头”与纠正“老虎尾”的对比。主材料使用完整句“伊礼拜三来上海”，比较日期整体作为新信息、只纠正星期几两个语境；另设“老虎头”的自然完整句族，防止结果只限于日期。

操作：每句由同人重复，匹配舒适语速；独立测目标语素的时长、强度和听辨突出，以及新AP边界和词汇调实现。焦点意图由提示记录，语音突出与分域由不同字段记录，避免见边界才定义重音。

假设结果A：中性读“(礼拜三)”，纠正读“(礼拜)(三)”；“三”的独立目标在多词族复现。结论：支持突出驱动的低层重组，反对固定一词一域的强版本；不能只据此断定所有域都是同一种音步。

假设结果B：两条件都是“(礼拜三)”，纠正时整个词的调域和时长增加。结论：证明焦点不必通过拆域实现；需要给D的推广增加词汇化、语素可对比性或调类条件。它不反驳端木原例曾存在。

假设结果C：日期词拆域，词汇化程度高的词只整体扩展。结论：将“焦点必拆域”改为受词内结构条件限制的假说；新词项盲测确认后才凝练规则。

### D2 音节数和语速是否比固定词界更有解释力

材料：核验词性和形态身份的较长单位，例如“上海语言学校”仅作候选，再建立若干三、四、五音节词／短语家族。每一字串在舒适、较慢、较快三速度下重复，长度比较在不同词族间进行，不能假装只改字数而词汇完全不变。

假设结果A：同一四音节单位慢读常“(甲乙)(丙丁)”，快读更常整体；变化伴随非首域首目标的消失，仍被认为自然。结论：支持语速参与域重组，固定词映射不充分；需要进一步比较具体音步算法是否事先预测正确分割位置。

假设结果B：快读只缩短时长，分域和调目标不变。结论：该范围的语速影响是语音实现，不能声称音系域合并。

假设结果C：同长度不同词项的分域长期不同，速度影响很小。结论：词汇或形态约束不可省，单纯每两音节组足不够。注意“两音节一足”只是待检算法组成，非端木整套理论的唯一主张。

### D3 默认非中心语突出是否提供额外预测

材料以复合词“纸箱”和动宾“买书”说明机制，正式筛选若干同长度复合名词与动宾短语，放入自然、全新信息的完整句。匹配目标音节读音和位置，能构造同音或近似控制时优先；不能将所有差异归因中心语关系。

假设复合词左成分更突出、动宾宾语更突出，并且加入这一默认突出候选后，新词族的边界预测改善。结论：支持该信息的解释与预测价值。若只改善训练句、换词后消失，说明词汇记忆，不能算非中心语规则迁移。若声学突出支持而分域预测不改善，说明突出并不足以决定边界。

## 3 R的验证

### R1 AP与ip是否需要分开

材料：“假使伊来，小李就要走”，舒适／慢／快三条件，同人两轮。独立听者判断“来”后较强分组，另组测量人员记录音段延长、目标重置和静音；不要先用四项定义筛出ip，再用同四项证明ip存在。

假设结果A：部分读法“来”后有较强听感和延长重置，但无静音；其他读法仅普通AP连接。结论：支持至少区分两个分组强度，AP与静音两种标签不够；与R的ip分析相容。

假设结果B：听感呈连续渐变，延长与重置不共同聚类。结论：离散ip标签可能过粗，应保留连续线索并检验有序／连续模型；不是强行给所有中间实例标3。

假设结果C：清晰模式只见年长者，中青年没有稳定模式。结论：限制R的代际外推，提出年轻人层级实现变化的假说；需要更多年长者，4人仅作探索对照。

### R2 焦点类型与跨NP去重音

与SS2共享材料和录音，不另录一套无法比较的数据。R的关键可检命题是“纠正”和“普通窄焦点”是否造成不同后焦点行为。

假设纠正条件70%的可用录音显示目标显著弱化至不可辨，窄焦点仅15%，且多位说话人、多词族一致。结论：支持焦点类型的条件效应；比例为教学数字，应报告混合效应与区间，不以70%为预定成功门槛。

若只有主观愤怒强度能解释差别，控制情绪后区别消失，则需将情绪／强调程度纳入解释，不能简单说纠正语义必定去重音。新增平静纠正与情绪强烈但非纠正两种语境作扩展，先做自然度小试。

### R3 IP边界调和词汇调是否各自有作用

材料以“伊来过上海”“伊来过上海伐”“伊阿是来过上海”比较句式，再以图39“勿是”启发同字串中性报告／纠正应答。保证每种功能有多个末AP调型和不同词项，不让一个末词代表一种句式。

假设结果A：助词问句末端常有额外高目标，但正反问没有；同字串“勿是”在纠正下额外出现低目标。结论：支持IP事件与词汇调分开编码，也说明问号不能替代句末类型。

假设结果B：问句末端变化全部可由助词词汇读音及长度解释，没有额外功能对应。结论：对这批年轻人的H%分析需要谨慎；设计同字串不同功能与不同末词同功能交叉材料再区分。不能拿B比A多一个音节的差异直接证明边界调。

### R4 调目标拥挤和跨域互动

子实验一：固定末端调型、句末功能与助词，构造长短AP。图37低尾覆盖、图38低尾提前是线索，不是长度单因素实验。

假设短AP中La不显现，长AP中La提前后仍出现H%，且随可用时长连续变化。结论：支持时序空间参与调目标协调，可扩展为根据时长预测提前／覆盖概率的模型。如果变化只随说话人而非时长，先考虑个体策略，不能归因长度。

子实验二：固定相邻AP边界，比较“(L*+H)(H* La)”与其他调序列。假设前+H独立峰值变弱，但独立听感和时间线索仍支持两个AP。结论：支持跨域目标互动，反对“拐点少一个就是域少一个”。如果同时所有边界证据消失，合域解释仍需保留，不能为了R强行保留两个AP。

### R5 三类抽象音高重音能否适用于年轻人

这是次要诊断而非三个月全面音系重建。保留传统五调和清浊／气声、喉塞属性，选每调多个词，在相同句架的短长AP中录音。比较R式三类加音段条件的模型与五调表示模型，使用相同网络容量、词项划分与训练预算。

假设三类模型对T2／T3某些年轻词项持续混淆，五调模型在未见词项更好；如果差别伴随气声减弱，结论为R抽象表示的年轻人适用性受限。模型优势不能单独证明音位数，还需感知辨别与独立音段证据。若两模型相当且区间宽，结论未定，不删除五调信息。

## 4 共同的实施与统计约定

第一批只做SS2与R2共享焦点实验、R1条件句、D1词内对比、R3句末事件四项，每项1个开发句族、每族3条件、2遍、4名中青年，共96条小试。D1第三条件为全句广焦点；所有材料先确认自然。其余验证卡作为扩展，不在三个月中强求全部完成。

小试合格后，每项扩至6个独立新句族，按实际招募人数和标注成本扩量。受控对照需要同人同句重复；神经网络最终测试又需要未见句族。两种目的使用不同的冻结评估表，不将“条件对照共享字串”错误地当作预测泛化。

边界概率用混合效应模型，连续F0与时长用匹配词项及说话人条件的回归；报告效应量、区间和个体差异。统计上的未显著只说明证据不足；充分窄的区间才能排除事先定义的有实际意义差异。

把S&S的确定性预测、D的突出／音步预测、R的事件约束分别实现为可审计基线或辅助特征，并与同容量纯文本神经网络比较。R没有现成任意文本分域算法，不得称自建网络为“Roberts原模型”。更准支持预测价值，不直接证明语言的心理机制。

最终结论示例：“在本研究中青年市区上海话、经验证的纠正语境中，宾语NP左边缘不能稳定阻断后焦点弱化；该结构约束需与焦点类型共同建模。”这个结论有对象、条件和现象，比“S&S错了”更可检验，也能指导TTS前端。
