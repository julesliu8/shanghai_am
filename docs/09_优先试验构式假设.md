# 优先试验的十类构式假设

日期：2026-09-09。性质：从 `jieba/docs/TONE_TOP20_CONSTRUCTIONS_20260908.md` 及相关老笔记筛出的工作假设，不是已验证规则、gold 或录音清单。选择标准是：构式内部或相邻成分的结构有理由改变低层 AP 的成组倾向，且能用换词和最小对照检验。所有例句都须母语者确认字词、读音和自然度。

## 十类首轮候选

|编号|构式及建议对照|优先观察的音节间隙|为什么可能影响界线|主要反例／风险|
|---|---|---|---|---|
|C01|实词＋虚词附着：V＋仔／了／过；同V无虚词|虚词前后、后续N左缘|功能成分可能并入前一域，后续实词可能重新起域|虚词身份和句末用法混淆；不把标点当证据|
|C02|普通动宾 vs 词汇化动宾|V—O|相同表面V＋N可能因词汇化程度形成不同域|旧 `jieba` 的 `vn` 只能作候选线索，不能直接当gold|
|C03|修饰语＋个＋名词（含关系小句）|个前后、中心语左缘|修饰范围和结构助词可能改变中心语起域位置|短定语、关系小句、量词“个”需分开；长结构易受音节数影响|
|C04|数量／指量NP与谓词后数量成分|数—量、量—N、V—数量成分|数量成分可能是NP内部、宾语或时量／动量补语，边界位置随角色变|确数、概数、指量意义不可混采；沿用老笔记时须重核上海话读法|
|C05|复合词、专名与生产性长词（二至五音节）|词内各间隙及词末|词汇化、长度和音步可能共同决定“一词一域”或内部再分域|语速只作已知控制变量；不把时长变化直接解释为边界变化|
|C06|结果补语：V＋结果、V＋结果＋O、V＋O＋结果|V—结果、结果—O、O—结果|补语与宾语的层级和词序改变相邻成分的成组关系|不能把 `RESULT` 标签改名当作语音证据；三种词序不假设可自由互换|
|C07|潜能：V＋得／勿＋结果或趋向|V—得／勿、得／勿—结果、结果—O|得／勿位于潜能内部，可能与普通否定、趋向链产生不同边界|“看勿过来”与普通否定、程度结构字串相似但构式不同|
|C08|重叠动词：AA／ABAB，带宾语或结果|重叠内部、重叠—O／补语|重复可能是构词、试行或话语重复，三者的域组织未必相同|试行“看”另记；犹豫、纠正和不流利重复排除核心集|
|C09|体貌与持续／进行标记：V＋过／了／辣|标记与V、标记与后续成分|附着层级不同，可能改变前后成分是否保持同一AP|“辣”须分处所、进行／持续、程度补语三型，不能一条规则处理|
|C10|历史五字组分式在当代整句中的迁移|二三、三二、二一二、二二一、一四等分式内部|老笔记的分式提供长度与局部分域候选，可检验能否迁移到陌生词项|1983年“广用／窄用式”不是焦点术语；历史描写不能直接当当代gold|

## 使用办法与当前问题

首轮仍以 C01、C02、C03、C06 为核心，C04、C05、C07、C08、C09、C10 作为扩展或共享材料。每类至少准备多个独立句族和可替换词项；同一句可有多个构式标签，但统计按句族去重。先做中性语境双人试标，保留 `uncertain`；若某类自然度差或不确定比例高，暂不扩量。

本清单解决的是“先测什么”的假设选择，不解决实际AP位置。仍待确认：年轻说话人的词汇化差异、长词的长度效应、`辣`及体貌标记的附着、历史分式对当代口语的迁移，以及局部结构在陌生词项上的泛化。焦点、停顿、句末语调和连续F0不作为本清单变量。
