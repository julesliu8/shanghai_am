# 变调界限预测范围修订评估

## 1 修订结论

2026年9月9日，项目决定把研究重心收窄为低层变调域／AP界限预测，焦点、停顿、ip、IP、句末语调和连续F0暂不研究。本轮据此重写00、04、05、06、07及两份Word，并在01至03顶部标为不再执行的前版记录。

收窄后，研究问题、材料、标注、模型和评价现在围绕同一个输出：一句n音节话语的n减1个内部位置是否为AP边界。

## 2 已从当前范围移除的内容

| 内容 | 原来可能承担的角色 | 当前处理 |
|---|---|---|
| 普通窄焦点与纠正焦点 | 实验变量、模型输入、标注标签 | 不诱导、不标注；明显依赖焦点的自然样本进未来集 |
| 停顿时长 | 边界证据、预测或测量变量 | 不研究；只作错读、不流利和切分质检 |
| ip与IP | 高层韵律输出 | 不标注、不预测 |
| Break 0至4 | 多级连接强度 | 停止扩展；改为AP边界0／1／uncertain |
| H% L% % | 句末边界事件 | 不标注、不建模 |
| H* L*+H等逐事件标签 | AM音高事件输出 | 只作理解AP调型的背景，不要求逐事件gold |
| 连续F0和时长生成 | 原T3任务 | 暂停；TTS只保留边界接口演示 |
| 问句类型与焦点条件 | 受控实验 | 移出三个月计划 |

移除不表示这些现象与AP永远无关，而是本阶段不把它们当作可解释变量。核心数据因此应使用中性、自然、无刻意纠正或对比的材料；难以剥离的实例公开记录排除理由。

## 3 保留并强化的内容

- 音节、词、语素和AP的分层。
- 词典调类与实际连读调型的区别。
- S&S的低层实词边缘与功能成分附着。
- 端木的非焦点音步、长度、语速、结构与词汇化机制。
- Roberts的AP表示、多读法与不确定性思想。
- C01至C08中能够形成低层边界对照的结构。
- L0至L4结构信息消融。
- 未见句族、说话人和来源的冻结测试。
- AP边界Precision、Recall、F1、整句匹配和Top-k候选评价。
- 纯人工与AI辅助的固定预算标注效率比较。

## 4 修订后的主要风险

第一，焦点等被排除后，核心语料分布会变窄。报告必须把结论限定为普通中性语境，不能冒称覆盖所有自然话语。

第二，AP gold仍需可靠的调型证据。删除高层标签不会自动提高低层一致性；应先小规模双标，若`uncertain`过高就继续缩小构式范围。

第三，停顿不再作为研究对象，但录音中的不流利仍会污染边界判断。质量控制必须保留`excluded_reason`，不能把所有含静音样本直接删掉而不留记录。

第四，语速仍可能影响AP分域。只有计划语速可作为文本前端可知条件，目标录音实际时长和F0不能输入模型。

第五，旧jieba标签和历史四五字分式可提供候选，但仍需当代说话人、陌生词项和自然整句验证。

## 5 当前尚待确认

1. 可招募人数和已有自然口语净时长。
2. AP边界双标的一致性及`uncertain`比例。
3. C01至C08中哪些句子在中性语境下自然。
4. 年轻说话人的词典调类与域内调型怎样对应。
5. L0至L4中哪一级对未见句族有稳定增量。
6. 现有TTS前端接受边界输入的具体格式。

以上问题只能用材料审阅、录音、双标和冻结测试回答，不能靠文档补写提前得出结论。
