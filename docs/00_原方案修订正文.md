# 低资源条件下上海话变调界限预测研究

首次进入项目的读者请先读[本科生导读与术语例解](07_本科生导读与术语例解.md)。本文件规定2026年9月9日以后执行的研究范围；01至03号文档仅保留为前版记录。

## 概要

本课题现在只研究一个核心任务：给定上海话文本、词典读音以及可在合成前获得的结构信息，预测每两个相邻音节之间是否存在低层变调域界限。本文把这一低层单位记作AP；项目主要输出是AP边界序列，而不是焦点、停顿、中间短语、语调短语或连续音高曲线。

研究以中青年市区上海话使用者为主，年长者只在资源允许时作为探索对照。低资源条件下，重点比较词界、词性与构词、局部句法和全句结构能否提高陌生句族上的边界预测。句法与变调域的对应关系仍是待验证假说，词汇化、音节数和语速也可能改变分域。

焦点、停顿、ip、IP、句末H%或L%和连续F0生成暂不研究，不进入核心标签、模型输入、评价指标或理论成败判据。核心材料使用无刻意纠正和对比的中性语境；自然语料中明显依赖焦点或含不流利停顿的句子进入`excluded_or_future`清单，不强行标成普通边界样本。

## 研究问题

1. 仅凭汉字或音节序列，低层变调界限能预测到什么程度？
2. 词界、词性、虚实词、构词和词汇化信息分别提供多少增量？
3. 动宾、动补、数量、修饰、嵌入等局部或全句结构能否改善未见句族预测？
4. 人工总结的边界规则能否在新词项、新句族和新说话人上迁移，并与小型神经模型互补？
5. 在固定人工时间内，AI预标能否增加经独立质检合格的AP边界标注？

当前不回答“焦点落在哪里”“哪里应该停顿”“是否存在ip或IP”“句末该升还是降”和“怎样生成完整F0曲线”。这些问题不再占用三个月周期的采集、标注和建模预算。

## 任务定义

一句话有n个音节，就有n减1个相邻位置。对每个位置预测`0=同一AP内部`或`1=AP结束`。例如九音节教学句“假使伊来小李就要走”共有八个候选位置；某个示意分域`(假使)(伊)(来)(小李)(就要)(走)`可转成边界序列`0 1 1 1 0 1 0 1`。该序列只是格式示范，不是这句话的正式读法。

主任务是二分类AP边界。模型可以额外输出每个位置的边界概率和前k个合法整句候选，但不得把词界直接复制为答案。若一条录音有两种都可接受的低层分域，应保留候选集合或分布；主评测同时报告严格单一gold和多参考候选覆盖。

本项目的“变调界限”不等于书写标点、真实静音或所有韵律层级。标注者判断的是低层连读变调组织是否在该音节后结束。停顿只用于发现录音不流利或切分问题，不作为待预测标签。

## 优先结构与候选例子

所有句子均需母语者审阅。括号只表示待检验的AP候选，不预定正式读法。

### C01 实词与虚词附着

候选“老师买仔书”“阿姐看仔报纸”。检查体貌成分是否并入前一动词域、后续实词是否另起域。比较`(老师)(买仔)(书)`等规则候选，重点检验实词左边缘和虚词附着的预测价值。

### C02 普通动宾与词汇化动宾

比较生产性动宾和已经词汇化的动宾式组合，例如旧jieba标签中的`vn`只作为候选来源。检验表面相同的V加N结构是否因词汇化程度形成不同界限。旧标签必须由当前标注者重新审阅。

### C03 动补与潜能结构

候选“伊推开门”“伊推勿开门”，另建多个自然句族。检查动词、结果补语、否定成分和宾语之间的AP边界。正式比较匹配音节数和词项，不使用停顿或焦点操纵。

### C04 数量结构

比较确数、概数及普通数量短语，但只研究它们是否产生不同AP边界。语义释义用于确定结构，不把数量焦点作为实验变量。上海话材料须独立核验，不能直接复制绍兴话或普通话读法。

### C05 复合词与长词

比较二至五音节复合词、专名和生产性组合，记录词汇化程度与实际语速。检验固定一词一域、按长度分足等候选规则。较快或较慢条件可以保留，因为语速可能改变低层分域；不记录高层停顿类型。

### C06 修饰与关系结构

候选“我老欢喜个人来上海”等仅作材料起点。重点检查修饰成分、结构助词、名词中心语和后续谓词附近的低层边界。关系小句结构可以作为模型输入，但不研究小句边缘是否形成ip。

### C07 主谓和嵌入边缘

比较简单主谓、宾语小句和嵌入结构中的实词／代词起点，检验全句结构相对局部词性是否提供额外边界信息。出现明显纠正、强对比或不流利停顿的录音不进入核心集。

### C08 历史四五字分式迁移

从旧jieba文献笔记中的一二、二一、一四、二三、三二等分式抽取可自然成句的材料，检验历史描写能否迁移到当代陌生词项。广用式／窄用式是历史分式术语，不等于广焦点／窄焦点；本轮不设计焦点条件。

第一批优先C01、C02、C03、C05，各做若干独立句族；C04、C06至C08在自然度审阅通过后扩展。选择标准是能否形成不同AP边界预测，不再以焦点范围、停顿或句末语调为优先级依据。

## 数据与核心标注

自然口语仍是目标领域，人工设计后真人录音用于结构控制。自然语料保留上下文以判断字词和结构，但核心模型不读取人工焦点标签或停顿时长。电视剧材料单独记录来源与授权，仅作域外测试候选。

每条核心样本保留五类信息：

1. 音频与元数据：`utterance_id、speaker_id、source、session、sentence_family、speech_rate、split`。
2. 音节与读音：逐音节时间、汉字、IPA、传统调类；未知写UNK。
3. 词法与结构：词界、词性、构词、词汇化、局部句法和必要的全句跨度。
4. AP边界gold：每个相邻音节位置的0／1标签、候选集合、置信度和裁决记录。
5. 质量控制：噪声、错读、F0不可用、明显焦点依赖、不流利停顿等排除原因。

Praat只需`syllable、word、AP、misc`四条核心轨道；结构与元数据放对齐JSON。F0曲线可作为标注AP的辅助证据和质检图，不形成AM音高事件标签，也不作为模型的预测目标。暂停建立`tones`和`breaks`核心轨道；已有旧标注只归档，不扩展。

双标者先独立听辨和检查域首／域内调形，再结合词典读音、波形和频谱裁决。标注手册必须列出可观察证据，但不能按理论规则预填gold。对无法可靠判断的边界保留`uncertain`并从严格主损失中屏蔽。

## 理论基线

本轮只实现能输出低层AP边界的理论部分。

### S&S低层边缘基线

按Selkirk与Shen的`Left Lex⁰`思想，在N、V、A等词汇性中心语左边缘提出新域，并为功能成分实现可审计的附着规则。保存每条边界由哪个词性和规则触发。MaP、焦点后删调和高层Top-Down Effect暂不验证。

### 端木重音与音步基线

根据词内部结构、非中心语突出候选、音节数、词汇化和语速产生低层分域候选。因为本轮不研究焦点，删除词内纠正焦点条件；“老虎头”等例子只作为理论背景，不进入核心实验。重音候选必须来自预先写明的结构规则，不能从gold边界反推。

### Roberts低层表示参考

借用Roberts把低层变调单位表示为AP、允许同一句有分组变体和保留不确定性的做法。项目不实现其ip、IP、Break 0至4、焦点类型、句末边界调或完整AM音高事件系统，也不把边界网络称作“Roberts模型”。

## 模型与消融

保留五种模型可见信息：

| 等级 | 输入 |
|---|---|
| L0 | 汉字或音节序列 |
| L1 | L0加词典读音与词界 |
| L2 | L1加词性、虚实词、构词和词汇化 |
| L3 | L2加局部句法与构式 |
| L4 | L3加全句跨度和嵌入结构 |

主模型采用字符／音节BiLSTM或小型Transformer，对每个相邻位置输出AP边界概率。起始配置可沿用128维嵌入、一层双向LSTM、0.2 dropout、Adam学习率0.001、batch16和早停；固定多个随机种子。另比较规则基线、CRF或线性分类器，避免低资源情况下只报告复杂模型。

人工结构与自动结构分别测试。自动parser使用折外预测或冻结版本，不能读取最终测试标签。模型不输入焦点类别、真实停顿、目标音频F0或实际音节时长；若使用计划语速，必须在合成前可知并与目标录音测得的真实语速分开。

输出必须经过合法性检查：句末视为AP结束，不允许空域或交叉层级；Top-k候选去重并限制数量。若一句有多个可靠参考分域，训练和评价明确采用集合标签、软标签或多参考匹配中的哪一种。

## 数据划分与评价

自然口语目标仍为至少60分钟有效材料，按说话人和会话关系优先隔离，再尽量接近36／12／12分钟训练、开发、最终测试。人工材料按完整句族隔离；同一字串的速度条件、重复和近似改写不能跨集合。小试材料全部进入开发集。

主要指标为音节间AP边界Precision、Recall和F1，以及整句完全匹配率。补充报告Top-k候选覆盖、不合理候选率、每句边界数偏差、按构式／说话人／句长分层的区间。模型阈值只在开发集选择，最终测试只运行冻结版本。

边界F1只判断位置，不设置毫秒容差；标签单位已经是离散音节间隙。若音节转写本身错误，先修B层，不把对齐误差算成边界容差。统计时以说话人和句族为抽样层级，不能把同一句重复或每条F0采样点当成独立样本。

神经消融只说明某类结构信息对预测有无增量，不单独证明音系机制。理论规则的评价同时报告覆盖：只在少量位置作出预测的高精确率规则，不能与覆盖全部位置的模型直接只比一个F1。

## 三个月执行与交付

第1至2周：冻结二分类边界schema，审阅C01至C08材料，确认可招募人数和自然录音量；两名学生完成20至30条试标，修订边界证据说明。

第3至4周：完成约96条中性语境小试和双标，计算AP边界一致性、每条耗时与不确定比例；冻结词典、句族和开发集。

第5至8周：采集自然口语并完成核心结构受控录音；建立L0至L4输入、理论规则基线和小型神经基线；每周审计错读、结构歧义、焦点依赖与不流利排除项。

第9至12周：在未见句族、说话人和来源上完成消融、规则迁移、Top-k和错误分析；进行固定预算的人机标注效率实验；用少量样例确认预测边界可被现有TTS前端消费，但不评价焦点、停顿或完整句调。

正式交付包括：低层变调界限定义、材料与匿名元数据、裁决后AP边界、结构特征、可审计规则、模型基线、冻结划分、错误分析和TTS接口示例。若AP标注一致性不足，优先缩小语料和构式范围，不增加高层韵律标签掩盖问题。

核心文献仍包括Selkirk与Shen 1990、Duanmu 2005和Roberts 2020，但只读取与低层变调域、词法句法映射、音步和AP识别直接相关的部分。焦点、ip/IP和句末语调文献保留在归档笔记，待后续课题启用。
